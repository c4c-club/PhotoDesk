# 04 · UI/UX 设计文档

---

## 1. 设计原则

| 原则 | 具体做法 |
|---|---|
| **手势优先** | 主路径只有"上下滑"，所有按钮都是次要入口 |
| **零误操作** | 破坏性动作：视觉锁定 + 触觉 + 确认 + 撤销，四重保险 |
| **照片是主角** | 全屏浏览页 100% 黑底、无边框、控件自动淡出 |
| **即时反馈** | 任何操作 100ms 内有视觉或触觉反馈 |
| **克制** | 不使用花哨动效；尊重"减弱动态效果" |

## 3. 页面清单与布局规格

### 3.1 照片库（Library）

```
┌─────────────────────────────────┐
│ 9:41  ⌄照片管家        🔍  ⚙︎   │  ← 导航栏（大标题滚动后收起）
├─────────────────────────────────┤
│ 全部 │ 收藏 │ 视频 │ 截图 │ 🔒  │  ← 分段切换，横向可滚动
├─────────────────────────────────┤
│  2026年10月 · 128 张            │  ← 粘性分组头
│ ┌──┐┌──┐┌──┐                   │
│ │  ││  ││▶ │  2pt 间距，圆角 4pt│
│ └──┘└──┘└──┘                   │
│ ┌──┐┌──┐┌──┐                   │
│ ...                             │
│                         ▐█▌     │  ← 月份快速索引条（右）
├─────────────────────────────────┤
│ ⊞多选  ✦清理  ⇅排序  ▦列数      │  ← 底部工具栏
└─────────────────────────────────┘
```
- 网格间距：2pt；列数 2–5；缩略图 `contentMode = .aspectFill`，`clipsToBounds`。
- 角标：视频（右下时长 `0:12`）、Live（左上 ◯）、截图（右下小图标）。
- 分组头：`2026年10月` + 副标题张数；点右侧「选择」进入该月多选。

### 3.2 全屏浏览（Viewer）★核心

```
┌─────────────────────────────────┐
│ ← 关闭                    ♡ ⓘ ⋯ │  ← 顶部栏，3 秒无操作淡出
│                                 │
│                                 │
│          [ 照片全屏显示 ]        │
│                                 │
│                                 │
│                                 │
│         ╭──────────╮            │  ← 动作浮层（拖拽时出现，居中偏上）
│         │    👁     │            │     上滑=隐藏 / 下滑=收藏
│         │  隐藏     │            │
│         ╰──────────╯            │
│                                 │
│  ───────────────────────────    │  ← 底部胶片条（可隐藏）
│  ▫▫▫■▫▫▫▫▫                      │
└─────────────────────────────────┘
```

**动作浮层规格**

| 属性 | 值 |
|---|---|
| 位置 | 上滑 → 屏幕上方 1/4 处；下滑 → 屏幕下方 1/4 处（跟随手指） |
| 尺寸 | 96×96 圆形背景 + 36pt SF Symbol |
| 透明度 | `0.35 + 0.65 × progress` |
| 缩放 | `0.85 + 0.30 × progress`（锁定后固定 1.15） |
| 位移 | 跟随手指 `dy × 0.6` |
| 颜色 | 收藏=琥珀 `#FFB300`；隐藏=靛蓝 `#5C6BC0`；移到最近删除=红 `#E53935`；加入相簿=青 `#26A69A`；分享=蓝 `#42A5F5`；信息=灰 `#78909C` |
| 锁定态 | 背景实心 + 图标放大 + 描边 2pt + `UIImpactFeedbackGenerator(.medium)` |
| 文案 | 图标下方 15pt 中黑字，如「松手隐藏」「松手加入收藏」「松手移到最近删除」 |

**Toast 规格**：距底部（含安全区）16pt，黑玻璃 `Material.ultraThin` 胶囊，左侧图标 + 文案，右侧「撤销」按钮 + 环形倒计时；5 秒后自动消失；上滑 Toast 可关闭。

**控件自动淡出**：3 秒无触摸 → 顶部栏/底部栏 opacity 0；点击屏幕切换显隐。

**手势教学页（Onboarding）**：全屏循环动画，一只手图标上下滑动，配合文字「上滑收藏 · 下滑隐藏」，底部「去设置自定义」按钮直达手势设置。

## 5. 视觉规范（Design System）

### 5.1 颜色（支持深色）

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `bgPrimary` | `#FFFFFF` | `#000000` | 网格背景 |
| `bgViewer` | `#000000` | `#000000` | 浏览页 |
| `bgSecondary` | `#F2F2F7` | `#1C1C1E` | 分组头、卡片 |
| `textPrimary` | `#1C1C1E` | `#F2F2F7` | 主文本 |
| `textSecondary` | `#8E8E93` | `#8E8E93` | 次文本 |
| `tint` | `#007AFF` | `#0A84FF` | 主色调 |
| `accentFavorite` | `#FFB300` | `#FFC233` | 收藏 |
| `accentHide` | `#5C6BC0` | `#8C9EFF` | 隐藏 |
| `accentDelete` | `#E53935` | `#FF5252` | 删除 |
| `separator` | `#C6C6C8` 30% | `#38383A` 60% | 分割线 |
| `glass` | `Material.regular` | `Material.regular` | Toast / 浮层 |

### 5.2 字体

| 场景 | 规格 |
|---|---|
| 大标题 | `.largeTitle` 34pt Bold（系统字体，支持动态字体） |
| 分组头 | `.headline` 17pt Semibold |
| 正文 | `.body` 17pt Regular |
| Toast | `.subheadline` 15pt Semibold |
| 角标 | `.caption2` 11pt Medium |

> 全部使用系统字体（`SF Pro`），**不使用自定义字体**（省体积、支持动态字体）。

### 5.3 图标

- 统一 SF Symbols 3（`iOS 15` 可用：`heart.fill`、`eye.slash.fill`、`trash.fill`、`folder.badge.plus`、`square.and.arrow.up`、`info.circle`、`photo.stack`、`sparkles`）。
- 尺寸：导航栏 22pt，列表 20pt，浮层 36pt。

### 5.4 圆角与阴影

| 元素 | 圆角 | 阴影 |
|---|---|---|
| 缩略图 | 4pt | 无 |
| 卡片 | 14pt | `0/2/8 rgba(0,0,0,0.06)` |
| Toast / 浮层 | 胶囊 | `0/4/16 rgba(0,0,0,0.25)` |
| 按钮 | 12pt | 无 |

## 6. 无障碍

| 项 | 要求 |
|---|---|
| VoiceOver | 每张缩略图：`accessibilityLabel = "照片，2026年10月3日，已收藏"`；`accessibilityTraits = .image, .button` |
| 手势替代 | 设置中提供「关闭手势」+ 每页底部常驻 3 个按钮（收藏/隐藏/删除），保证无手势也可用 |
| 动态字体 | 所有文本用系统 text style；浏览页浮层文案最大 20pt 上限 |
| 对比度 | 文本与背景 ≥ 4.5:1 |
| 减弱动态效果 | 飞出动画 → 淡出；转场 → 交叉溶解 |
| 减弱透明度 | 玻璃材质降级为实色 |
| 开关控件 | 使用标准 `Toggle`（自带无障碍） |
