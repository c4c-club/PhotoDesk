# 04 · UI/UX 设计文档

---

## 1. 设计原则

| 原则 | 具体做法 |
|---|---|
| **手势优先** | 主路径只有"上下滑"，所有按钮都是次要入口 |
| **零误操作** | 破坏性动作：视觉锁定 + 触觉 + 确认 + 撤销，四重保险 |
| **照片是主角** | 全屏浏览页 100% 黑底、无边框、控件自动淡出 |
| **即时反馈** | 任何操作 100ms 内有视觉或触觉反馈 |
| **克制** | 不使用花哨动效；尊重"减弱动态效果" |

### 3.2 全屏浏览（Viewer）★核心

```
┌─────────────────────────────────┐
│ ← 关闭                    ♡ ⓘ ⋯ │  ← 顶部栏，3 秒无操作淡出
│                                 │
│                                 │
│          [ 照片全屏显示 ]        │
│                                 │
│                                 │
│                                 │
│         ╭──────────╮            │  ← 动作浮层（拖拽时出现，居中偏上）
│         │    👁     │            │     上滑=隐藏 / 下滑=收藏
│         │  隐藏     │            │
│         ╰──────────╯            │
│                                 │
│  ───────────────────────────    │  ← 底部胶片条（可隐藏）
│  ▫▫▫■▫▫▫▫▫                      │
└─────────────────────────────────┘
```

**动作浮层规格**

| 属性 | 值 |
|---|---|
| 位置 | 上滑 → 屏幕上方 1/4 处；下滑 → 屏幕下方 1/4 处（跟随手指） |
| 尺寸 | 96×96 圆形背景 + 36pt SF Symbol |
| 透明度 | `0.35 + 0.65 × progress` |
| 缩放 | `0.85 + 0.30 × progress`（锁定后固定 1.15） |
| 位移 | 跟随手指 `dy × 0.6` |
| 颜色 | 收藏=琥珀 `#FFB300`；隐藏=靛蓝 `#5C6BC0`；移到最近删除=红 `#E53935`；加入相簿=青 `#26A69A`；分享=蓝 `#42A5F5`；信息=灰 `#78909C` |
| 锁定态 | 背景实心 + 图标放大 + 描边 2pt + `UIImpactFeedbackGenerator(.medium)` |
| 文案 | 图标下方 15pt 中黑字，如「松手隐藏」「松手加入收藏」「松手移到最近删除」 |

**Toast 规格**：距底部（含安全区）16pt，黑玻璃 `Material.ultraThin` 胶囊，左侧图标 + 文案，右侧「撤销」按钮 + 环形倒计时；5 秒后自动消失；上滑 Toast 可关闭。

**控件自动淡出**：3 秒无触摸 → 顶部栏/底部栏 opacity 0；点击屏幕切换显隐。

**手势教学页（Onboarding）**：全屏循环动画，一只手图标上下滑动，配合文字「上滑收藏 · 下滑隐藏」，底部「去设置自定义」按钮直达手势设置。

### 5.2 字体

| 场景 | 规格 |
|---|---|

### 5.4 圆角与阴影

| 元素 | 圆角 | 阴影 |
|---|---|---|
| 缩略图 | 4pt | 无 |

## 6. 无障碍

| 项 | 要求 |
|---|---|
| VoiceOver | 每张缩略图：`accessibilityLabel = "照片，2026年10月3日，已收藏"`；`accessibilityTraits = .image, .button` |
| 手势替代 | 设置中提供「关闭手势」+ 每页底部常驻 3 个按钮（收藏/隐藏/删除），保证无手势也可用 |
| 动态字体 | 所有文本用系统 text style；浏览页浮层文案最大 20pt 上限 |
| 对比度 | 文本与背景 ≥ 4.5:1 |
| 减弱动态效果 | 飞出动画 → 淡出；转场 → 交叉溶解 |
| 减弱透明度 | 玻璃材质降级为实色 |
| 开关控件 | 使用标准 `Toggle`（自带无障碍） |

## 附录 A · M10 新增/变更交互规格（docs/09，2026-11-03）

### A.1 会话式整理（替代逐张删除）

| 交互 | 规格 |
|---|---|
| 上滑/下滑标记 | 零弹窗零等待：入队 → 卡片飞出 → 下一张补位（上滑从底部顶上来、下滑从顶部压下来、末尾回卷与飞出同侧）；Toast「已标记待删除 · 撤销」/「已加入待隐藏 · 撤销」 |
| 顶部计数 | 查看器顶栏/照片库导航栏「待删除 N · 待隐藏 M」徽标，点开整理回顾 |
| 整理回顾 | 待删除/待隐藏缩略图分组，逐张「恢复」；「全部移到最近删除」= 唯一删除提交入口（一次系统确认，文案由系统控制）；「全部隐藏」批量提交 |
| 取消系统确认 | 队列保留，提示「系统未允许删除，N 张仍在待删除」 |
| 杀 App 重启 | 队列恢复，不自动提交、不自动弹系统框 |
| App 内确认 | **全部移除**（删除/隐藏均无 App 内二次确认；设置页不再有「破坏性操作确认」开关） |

### A.2 照片库

- 顶部五段切换：全部 / 收藏 / 视频 / 截图 / 已隐藏（已隐藏弹出 Vault，关闭回弹原视图）。
- 筛选栏：活动筛选 chips（可单删）+「筛选」面板（年/月/日三级 + 媒体多选 + 状态 + 位置）+ 清除 + 结果计数；筛选无结果空态「没有符合筛选条件的照片」+「清除筛选」。
- 位置筛选：离线聚类列表「37.3°N, 122.0°W 附近 · 128 张」，选中按 25 km 半径；有/无位置快捷项；不请求定位权限。
- 多选工具栏：取消 | 已选择 N 项 | 完成 + 操作行（全选/收藏/隐藏/移到最近删除/加相簿/更多⟨反选、取消全选、取消收藏、分享⟩）。
- 框选：长按 0.28s 进入多选，拖动 >10pt 进入框选（此时才禁滚动），边缘 <60pt 自动滚动；只加选不取消。
- 双指捏合：2–5 列实时吸附，锚点照片不跳，每次变档触觉，松手持久化，首次提示「双指捏合可调整列数」。
- 位置记忆：回到照片库自动滚到上次位置 + Toast「已回到上次整理的位置」（按视图+筛选分别记忆；设置可关/可清除）。
- 月份分组头右侧「选择」：进入该月多选。

### A.3 查看器

- 打开：点哪张开哪张（assetID 定位）；左右滑顺序与网格一致。
- 动作池（无「后续里程碑」文案）：加相簿（输入名称创建并加入）、分享（原件）、查看信息、旋转/编辑（编辑器）、长按操作菜单（收藏/隐藏/移到最近删除/加相簿/分享/信息/旋转）。
- 视频点击暂停/继续；双击缩放不再触发 chrome 切换（单击等待双击失败）。
- 删除/隐藏后：保持当前页（原位变成下一张），末尾回退一张，列表删空自动关闭；补位 0.96→1.0 缩放 + 16pt 位移进入。

### A.4 已隐藏（Vault）

- 进页自动唤起 Face ID（宽限 5 分钟免重复）；失败 → 原因 + 重试 + 设备密码；不可用 → 去系统设置（模拟器附「继续（仅模拟器）」）。
- 网格可点开查看器；长按菜单：取消隐藏 / 移到最近删除 / 收藏；待隐藏项合并显示（未提交也可见）。
- 空态「这里空空如也 / 在浏览页下滑即可隐藏照片」；受限授权提示允许完全访问。

### A.5 存储统计 / 安全设置

- 统计中：进度环 + 「已统计 N / M」+ 取消；软超时显示部分结果 +「部分 iCloud 资源大小未知」+ 继续统计；完成后图表 + 未知大小脚注；下拉强制重算。
- 设置 → 安全与锁定：启动时用 Face ID 锁定 / 「已隐藏」需要 Face ID / 后台宽限（立即/15/30/60s）/ 立即锁定。
- 设置 → 外观与网格：记住上次整理位置（默认开）+ 清除位置记忆。

### A.6 文案口径（docs/04 §7 增补）

| 场景 | 文案 |
|---|---|
| 滑动标记删除 | 已标记待删除 · 撤销 |
| 滑动标记隐藏 | 已加入待隐藏 · 撤销 |
| 批量提交成功 | 已移到系统「最近删除」N 项 / 已隐藏到系统「已隐藏」相册 N 项 |
| 系统确认取消 | 系统未允许删除，N 张仍在待删除 |
| 位置恢复 | 已回到上次整理的位置 |
| 删除语义 | 全部为「移到最近删除」；「彻底删除/永久删除」仅出现在否定句说明 |

## 附录 B · M11 稳定性修复交互规格（docs/13，2026-11-04）

### B.1 照片库

| 交互 | 规格（变更点） |
|---|---|
| 顶部布局 | **移除筛选栏整行**（chips/「共 N 项」不再常驻）；只剩五段 ScopePicker + 网格，多出约 50pt 内容空间 |
| 筛选入口 | 导航栏 trailing「筛选」按钮（`line.3.horizontal.decrease.circle`，active 实心）+ 多选操作行首位「筛选」（全选左侧）；chips 展示移入筛选面板顶部「当前条件」（含「清除全部条件」） |
| 筛选面板 | 「应用筛选（预计 N 项）」计数 200ms debounce 后台计算，期间显示「计算中…」（不再卡主线程） |
| 月份跳转 | 导航栏「月份」按钮（calendar）→ 月份面板：按年份分组 + 3 列卡片（月份名 + N 张，空月置灰）；点卡片跳转；卡片右上「全选」；顶部「回到顶部」 |
| 月份分组头 | 标题可点 = 跳到本月；右侧 `⋯` 菜单「选择本月全部 / 跳到本月」（替代旧「选择」按钮） |
| 跳转反馈 | 1.5s 顶部细横幅「已跳到 2024年5月」，不挡网格；跳转后立即持久化位置（杀进程也记住） |
| 月份索引条 | 保留右侧细条；拖动时左侧浮层显示「2024年5月」；AX 标识 MonthIndexBar（共 N 个月） |
| 多选滑动选择 | 长按 0.15s 即可按住拖动连续选中（不再要求静止 0.28s + 10pt 内）；松手/快速滑动仍正常滚动；首次进入多选顶部提示「按住照片滑动可连续选择」 |
| 单月全选 | 「选择本月全部」→ 计数「已选择 N 项 · 本月」；范围仅该月（相邻月不选中）；再点「全选」在月内归零 |
| 位置记忆 | 恢复成功不再弹底部 Toast；保存时机加密（滚动停止 0.3s / 停止拖拽 / 切后台 / 切 Tab / 跳转完成） |
| 底部气泡 | **不再常驻**：Toast 显示完即隐藏、不拦截触摸（仅「撤销」按钮可点）；捏合/滑动选择提示改为顶部细横幅 |

### B.2 查看器

| 交互 | 规格（变更点） |
|---|---|
| 捏合缩放 | 重写缩放几何（ZoomGeometry）：1×–5×、双击点击点为中心 1×↔2.5×；无图/未布局时禁用捏合；DEBUG 横幅 `zoom=` 恒为有限数字 |
| 删除/隐藏 | 删除事务化：卡片 snapshot 飞出与数据源变更解耦，同一 runloop 完成「数组移除 + cell 删除」；删除首/中/末张、连续删除均不跳首页不闪退 |
| 连滑 | 预取有界（窗口 ≤7、大图 ≤2048px、回看命中 60MB 缓存、离屏取消）；DEBUG 横幅 `load=` ≤3 |
| Toast | 位置在胶片条上方，随 chrome 淡出；只有「撤销」可点，其余区域穿透 |
