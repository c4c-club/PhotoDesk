## 3. 模拟器构建与运行（无需签名）

```bash
#!/usr/bin/env bash
# scripts/build-sim.sh
set -euo pipefail
SCHEME=PhotoDesk
DEVICE_NAME="${1:-iPhone 13}"
RUNTIME="${2:-iOS-15-5}"

xcrun simctl list runtimes                       # 确认 iOS 15.5 runtime 已下载
xcodebuild \
  -project PhotoDesk.xcodeproj \
  -scheme "$SCHEME" \
  -configuration Debug \
  -sdk iphonesimulator \
  -destination "platform=iOS Simulator,name=$DEVICE_NAME,OS=15.5" \
  -derivedDataPath build/DerivedData \
  build

APP=$(find build/DerivedData/Build/Products -name "*.app" -maxdepth 3 | head -1)
xcrun simctl boot "$DEVICE_NAME" 2>/dev/null || true
open -a Simulator
xcrun simctl install booted "$APP"
xcrun simctl launch booted com.example.PhotoDesk
```

### 3.1 往模拟器导入测试照片

```bash
# scripts/sim-photos.sh —— 生成 300 张尺寸/内容各异的测试图
mkdir -p /tmp/simphotos
python3 - <<'PY'
from PIL import Image, ImageDraw
import random, os
os.makedirs('/tmp/simphotos', exist_ok=True)
for i in range(300):
    w,h = random.choice([(4032,3024),(3024,4032),(2048,2048),(1920,1080)])
    im = Image.new('RGB',(w,h),(random.randint(0,255),random.randint(0,255),random.randint(0,255)))
    d = ImageDraw.Draw(im); d.ellipse([w*0.2,h*0.2,w*0.8,h*0.8], fill=(255,255,255))
    im.save(f'/tmp/simphotos/p{i:04d}.jpg', quality=85)
PY
xcrun simctl addmedia booted /tmp/simphotos/*.jpg
```

> 大规模性能验证：生成 12,000 张（用小尺寸图即可，PhotoKit 不关心内容）。
> **注意**：模拟器照片库写入较慢，1.2 万张建议分 10 批 `addmedia`。

### 3.2 模拟器注意事项

- 模拟器**没有 Face ID**：`LAContext` 会失败 → DEBUG 下提供"模拟器跳过生物识别"开关（`BiometricGate` 检测 `targetEnvironment(simulator)`）。
- 模拟器照片库无 iCloud-only 资源，iCloud 分支需在真机验证。
- iOS 15 模拟器性能 ≠ 真机，性能结论以真机为准。

## 4. 真机自签名（免费 Apple ID）

### 4.1 能力边界（必须遵守）

| Capability | 免费账号 | 本项目是否需要 |
|---|---|---|
| iCloud / CloudKit | ❌ | 不需要 |
| App Groups | ❌ | **不需要（Core Data 放默认沙盒）** |
| Push Notifications | ❌ | 不需要 |
| Keychain Sharing | ❌ | 不需要 |
| Associated Domains | ❌ | 不需要 |
| In-App Purchase | ❌ | 不需要 |
| Game Center / HealthKit / Wallet / Siri | ❌ | 不需要 |
| 后台模式（除少数） | 受限 | 不需要（后台扫描用 `beginBackgroundTask` 即可） |

→ **结论：本项目功能完全落在免费账号能力范围内，可自签名。**

### 4.2 限制

| 限制 | 值 |
|---|---|
| 证书有效期 | **7 天** |
| App ID 数量 | 7 天内最多注册 **10 个** App ID（业界常称 3 个，实际上限随政策变化，以 Xcode 报错为准） |
| 注册设备 | 每年最多 100 台 |
| 同时安装的自签名 App | 设备上通常 3 个 |

### 4.3 命令行签名与安装

```bash
#!/usr/bin/env bash
# scripts/sign-device.sh
set -euo pipefail
TEAM="XXXXXXXXXX"                      # 免费 Apple ID 的 Team ID
BUNDLE="com.example.PhotoDesk"

xcodebuild \
  -project PhotoDesk.xcodeproj \
  -scheme PhotoDesk \
  -configuration Debug \
  -destination 'generic/platform=iOS' \
  -allowProvisioningUpdates \
  -allowProvisioningDeviceRegistration \
  DEVELOPMENT_TEAM="$TEAM" \
  PRODUCT_BUNDLE_IDENTIFIER="$BUNDLE" \
  -derivedDataPath build/DerivedData \
  -archivePath build/PhotoDesk.xcarchive \
  archive

# 导出 ipa
cat > build/ExportOptions.plist <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>method</key><string>development</string>
  <key>teamID</key><string>TEAM_PLACEHOLDER</string>
  <key>signingStyle</key><string>automatic</string>
  <key>stripSwiftSymbols</key><true/>
  <key>thinning</key><string>&lt;none&gt;</string>
</dict></plist>
PLIST
sed -i '' "s/TEAM_PLACEHOLDER/$TEAM/" build/ExportOptions.plist

xcodebuild -exportArchive \
  -archivePath build/PhotoDesk.xcarchive \
  -exportPath build/ipa \
  -exportOptionsPlist build/ExportOptions.plist
```

安装到真机（任选其一）：

```bash
# A. ideviceinstaller（支持 iOS 15，推荐）
brew install ideviceinstaller libimobiledevice
idevice_id -l
ideviceinstaller -u <UDID> -i build/ipa/PhotoDesk.ipa

# B. Xcode GUI：Window → Devices and Simulators → + 选择 ipa
# C. ios-deploy（Xcode 15+ 可用 devicectl / xcrun devicectl）
```

### 4.4 手动重签（当签名失败时的兜底）

```bash
# 1. 列出可用签名身份
security find-identity -v -p codesigning
# 2. 生成 entitlements（ entitlements.plist 中 get-task-allow = true）
# 3. 重签
codesign -f -s "Apple Development: you@email.com (TEAMID)" \
  --entitlements build/entitlements.plist \
  build/Debug-iphoneos/PhotoDesk.app
```

### 4.5 续签方案

| 方案 | 说明 |
|---|---|
| **AltStore**（推荐） | Mac 上装 AltServer，Wi-Fi 自动在到期前重签，无需连电脑 |
| **SideStore** | 直接在手机上自签（需先有一次电脑签名） |
| 每周重签 | 手动跑一次 `scripts/sign-device.sh` |

> 建议测试期直接装 AltStore，一劳永逸。

## 5. CI（GitHub Actions，macOS runner）

```yaml
# .github/workflows/ios.yml
name: Build & Test
on: [push, pull_request]
jobs:
  core-linux:                      # ★ 无需 Mac：核心纯逻辑秒级验证
    runs-on: ubuntu-latest
    container: swift:6.0-noble
    steps:
      - uses: actions/checkout@v4
      - name: Test PhotoDeskCore
        run: swift test --package-path PhotoDeskCore

  build:
    runs-on: macos-14
    needs: core-linux
    steps:
      - uses: actions/checkout@v4
      - uses: maxim-lobanov/setup-xcode@v1
        with: { xcode-version: '15.4' }
      - name: Install xcodegen
        run: brew install xcodegen
      - name: Generate project
        run: xcodegen generate
      - name: Create simulator
        run: |
          xcrun simctl create CI-iPhone13 "iPhone 13" "com.apple.CoreSimulator.SimRuntime.iOS-15-5" || true
      - name: Build
        run: |
          xcodebuild -scheme PhotoDesk -sdk iphonesimulator \
            -destination 'platform=iOS Simulator,name=CI-iPhone13' build
      - name: Test
        run: |
          xcodebuild -scheme PhotoDesk -sdk iphonesimulator \
            -destination 'platform=iOS Simulator,name=CI-iPhone13' test
      - name: Build unsigned ipa（手机验证用，见 §7.4）
        run: |
          xcodebuild -scheme PhotoDesk -sdk iphoneos -configuration Release \
            -derivedDataPath build/DerivedData \
            CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY="" \
            -archivePath build/PhotoDesk.xcarchive archive
          mkdir -p build/Payload
          cp -R build/PhotoDesk.xcarchive/Products/Applications/PhotoDesk.app build/Payload/
          cd build && zip -qr PhotoDesk-unsigned.ipa Payload
      - uses: actions/upload-artifact@v4
        with: { name: PhotoDesk-unsigned-ipa, path: build/PhotoDesk-unsigned.ipa }
      - name: Upload derived data logs on failure
        if: failure()
        uses: actions/upload-artifact@v4
        with: { name: logs, path: build/DerivedData/Logs }
```

> 免费账号自签名**无法在 CI 完成**（需人工 Apple ID 登录 + 2FA）→ CI 只做模拟器构建 + 测试；真机包本地出。
> 想让 CI 全自动出真机 ipa，唯一路径是付费开发者账号 + fastlane match（见 §7.4 方案 C）。

## 7. 锁定方案：Windows 编辑 → Git 推送 → Actions 编译 → 手机验证

> **决策时间 2026-10-24（最终版）**。本节为唯一执行方案，此前所有"二选一 / 待定 / 决策树"表述**作废**。
> 两条已锁定的附加决策：① **不安装 Ubuntu**（不为一个测试环境引入 Linux 系统）；② **验证走真机**，不用云端模拟器。

### 7.1 环境事实（已探测，证据见 08）

| 探测项 | 实测 | 对本方案的影响 |
|---|---|---|
| OS | Windows 10 19045 原生（Git Bash/MINGW64） | 编辑端，不承担编译 |
| Xcode / `xcrun` | 不存在（exit 127） | 编译 100% 交给 Actions |
| 本机 iOS 模拟器 | 不存在 | 不影响——验证改走真机 |

| ZCode「iOS 模拟器」插件 | macOS 本地包装，含 `platform === "darwin"` 硬检 | 不装，搁置 |

### 7.2 决策：不装 Ubuntu，本地测试走 Docker 容器

**用户决策**：不需要 Linux 系统就不安装。→ **WSL2 Ubuntu 方案整体移除。**

Docker 恰好满足这个诉求：容器是一台"用完即弃的临时 Linux"，不进系统、不占发行版、不需要迁移或双系统。你机器上 Docker 已经装好了，只需启动 Docker Desktop。

```powershell
# 一次性：启动 Docker Desktop（应用没开则 daemon 起不来）
docker version                       # 确认 Server 部分有输出

# 日常：跑核心逻辑测试（在仓库根目录）
docker run --rm -v "${PWD}/PhotoDeskCore:/workspace" -w /workspace swift:6.0-noble swift test
```

> Git Bash 下用 `docker run --rm -v "/$(pwd)/PhotoDeskCore:/workspace" -w /workspace swift:6.0-noble swift test`。
> 已固化为 **`scripts/test-core.ps1`**，一条命令搞定，失败时非 0 退出（供 CI/本地共用）。

| | Docker `swift:6.0-noble`（采用） | WSL2 Ubuntu（已弃用） |
|---|---|---|
| 是否引入 Linux 系统 | ❌ 不引入，容器即临时环境 | ⚠️ 装一个完整发行版 |
| 安装成本 | 启动 Docker Desktop | 10–15 分钟 + 几 GB |
| 冷启动 | 容器启动开销（首次拉镜像较慢） | 无 |
| VS Code 集成 | Dev Containers 扩展（可选） | Remote - WSL |

**如果哪天连 Docker 都不想开**：可以直接跳过本地测试，全部依赖 Actions 的 `core-linux` job。代价是反馈从秒级变分钟级，可接受但不推荐。

### 7.3 决策：验证走真机 —— 而签名是这条路上唯一的坎 ★

**这是本方案最需要提前想清楚的一点**：

- 真机需要 `.ipa`，而 ipa 必须**签名**。
- **免费 Apple ID 无法在 CI 上自动签名**（需交互式登录 + 2FA，GitHub Actions 做不到）。
- 你的 Windows 本机又不能签名（没有 Xcode/`codesign`）。
- → 所以必须选一条：**CI 出未签名包 + Windows 上用 AltServer 签名**，或**买付费账号让 CI 全自动签名**。

#### 路径 A（免费，¥0）：CI 出未签名 ipa → AltServer 在本地签名安装

```
Actions 产出 PhotoDesk-unsigned.ipa
   → 下载到 Windows
   → AltServer for Windows（有官方 Windows 版）选 "Install IPA"
   → 用你的免费 Apple ID 签名并装到 iPhone（USB 或同 Wi-Fi）
   → iPhone 上装 AltStore → 到期前在同一 Wi-Fi 下自动续签（7 天一轮）
```

- ✅ 零成本，能真机验证手势（本项目最需要的就是真机手感）
- ⚠️ 7 天过期，需要电脑联网时自动续签；免费账号有 App ID 数量与设备数限制
- ⚠️ 每次装包要手动点一下 AltServer

#### 路径 B（付费，¥688/年）：CI 全自动签名，下载即装

```
Actions 用 App Store Connect API Key + fastlane match 自动签名
   → 产出已签名的 Ad Hoc / Development ipa（1 年有效）
   → 下载后 AltServer 安装，或上传 TestFlight 分发给最多 100 人
   → Xcode Cloud 还可直接云端编包（含 25 计算小时/月免费额度）
```

- ✅ 一条命令出包、1 年有效、可 TestFlight、解锁 iCloud/App Groups/推送等 Capability
- ⚠️ 年费 ¥688

| | 路径 A（免费 + AltServer） | 路径 B（付费账号） |

| 成本 | ¥0 | ¥688/年 |
| 有效期 | 7 天（AltStore 自动续签） | 1 年 |
| CI 自动化程度 | CI 出未签名包，签名在 Windows 手动点 | **全自动**，下载即装 |
| 分发 | 只能自己的设备 | TestFlight 可分 100 人 |
| 适合 | 自用、验证阶段 | 长期迭代 / 要给他人用 |

> **建议**：先用路径 A 跑通 M2（手势）阶段——那时你最需要的是"在手机上滑一下看看手感"，7 天续签完全够用。
> 等 M8 要频繁出包、或想给别人用时，再升级路径 B。**两条路的 CI 只差一个签名步骤，切换成本很低。**

### 7.4 CI 如何产出未签名 ipa（路径 A 的具体做法）

```yaml
# .github/workflows/ios.yml 中增加一步：产出未签名 ipa
- name: Build unsigned ipa
  run: |
    xcodebuild -scheme PhotoDesk -sdk iphoneos \
      -configuration Release \
      -derivedDataPath build/DerivedData \
      CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO \
      CODE_SIGN_IDENTITY="" \
      -archivePath build/PhotoDesk.xcarchive archive
    mkdir -p build/Payload
    cp -R build/PhotoDesk.xcarchive/Products/Applications/PhotoDesk.app build/Payload/
    cd build && zip -qr PhotoDesk-unsigned.ipa Payload
- uses: actions/upload-artifact@v4
  with: { name: PhotoDesk-unsigned-ipa, path: build/PhotoDesk-unsigned.ipa }
```

> 说明：`CODE_SIGNING_ALLOWED=NO` 产出未签名 `.app`，手动打成 `Payload/` + zip 即得未签名 ipa。
> AltServer 安装时会用你的 Apple ID 重新签名。

### 7.5 完整工作流（最终版）

```
Windows（写代码）
   ├─ scripts/test-core.ps1（Docker）→ swift test      ← 秒级
   ├─ swift-format / swiftlint（可选，也可在 Docker 里跑）
   └─ git push
         ↓
GitHub Actions macos-14
   ├─ [core-linux]  docker swift:6.0-noble → swift test        （秒级，先跑）
   ├─ [build]       xcodegen + xcodebuild build/test（模拟器，iOS 15.5）
   ├─ artifact: PhotoDesk-Simulator.app.zip   （UI 测试结果 + 备用）
   └─ artifact: PhotoDesk-unsigned.ipa        （手机验证用）
         ↓
Windows 下载 ipa
   ↓
AltServer(Windows) → iPhone
   ↓
真机验证：上滑/下滑手势、浮层跟手、Toast 撤销、Face ID 保险箱、清理流程
   ↓
性能（FPS/内存）看不了？→ 临时租一小时云 Mac 用 Instruments，或靠 CI 的 XCTMetric
```

**Appetize.io 的定位调整**：不再是主路径，降级为**可选补充** —— 当你手边没手机、或想快速给别人看一眼时用（上传 CI 的模拟器 `.app.zip` 即可）。真机才是验收标准。

**关于那个「iOS 模拟器」插件**：它是「Mac 上 Xcode Simulator 的遥控器」——把 `xcodebuild → simctl boot/install/launch → screenshot → idb 点按` 封装成 MCP 工具，**不含模拟器本体**。现在装了用不了；一旦有了 Mac，它能立刻建立完整闭环。**先记着。**

### 7.8 关于 iOS 模拟器（一句话结论，不再展开）

- Xcode Simulator **只能在 macOS 上跑**（`CoreSimulator` 是 macOS 专有闭源组件），Windows 上没有真的，iPadian 之类是桌面皮肤。
- 模拟器是**运行**环境不是**编译**环境 —— 它解决"怎么看效果"，不解决"怎么出包"。
- **本项目已改走真机验证**，模拟器只在 CI 里承担 UI 测试（`xcodebuild test`），以及可选的 Appetize 云端预览。
