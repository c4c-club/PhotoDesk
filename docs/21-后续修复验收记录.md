## 3 P1 · 查看器捏合崩溃根因重修（✅ 自动化，🟨 真机待验）

5. 边界：`ViewerViewController.setupPanGesture()` 上滑 pan 语义未改；`cancelsTouchesInView = false` 只加在 Library 网格新 pan（P3）。
6. **绿5 .ips 崩溃取证补根因**：25 份崩溃堆栈同型——面包屑字符串插值读 `scrollView.zoomScale` 在 `viewForZooming` 内重入 UIScrollView 委托查询（`_zoomScaleFromPresentationLayer → _getDelegateZoomView`）→ 无限递归栈溢出。修复 `36c0e7a`：面包屑改读 `zoomContentView.transform.a`（等价缩放值，绕开委托重入路径）。
