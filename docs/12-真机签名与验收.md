# 12 · 真机签名与验收（v1.1.0 Build 2）

> 本文是 Windows 用户把 CI 产出的**未签名 IPA** 装到 iPhone 的完整步骤，以及只能在真机上完成的验收清单。
> Agent 不执行真机操作；下表「待用户验证」项完成前，不应视为 D06/D09/D16 的真机部分已验收。

---

## 1. 前置条件

| 项 | 说明 |
|---|---|
| IPA | CI artifact `PhotoDesk-unsigned-ipa`（`PhotoDesk-unsigned.ipa` + `PhotoDesk-unsigned.ipa.sha256`），下载命令见 §4 |
| 电脑 | Windows 10/11；已装 iTunes（Microsoft Store 版即可）与 iCloud（Apple Devices 应用亦可）——USB 驱动依赖 |
| Apple ID | 免费 Apple ID 即可（签名 7 天有效）；付费开发者账号（¥688/年）可 1 年 |
| iPhone | iOS 15.0+；设置 → Apple ID → 媒体与购买项目 能正常登录 |

## 2. 签名安装（AltStore，推荐）

1. 电脑安装 [AltServer](https://altstore.io/)（Windows 版），运行后托盘出现菱形图标。
2. iPhone 用数据线连接电脑，解锁并点「信任」。
3. 托盘 AltServer 图标 → Install AltStore → 选择你的 iPhone；手机上输入 Apple ID 登录（AltStore 首次需要装到手机）。
4. 把 `PhotoDesk-unsigned.ipa` 通过 AirDrop/文件/网盘传到手机（或直接让手机浏览器下载），用**文件**App 打开 → 分享 → AltStore。
5. AltStore 开始签名安装（免费账号第一次可能要求在 设置 → 通用 → VPN 与设备管理 信任开发者证书）。
6. 安装完成后启动 App；**首次启动允许「照片 → 完全访问」**（受限访问下隐藏/筛选不完整）。

### 替代：Sideloadly
1. 电脑安装 [Sideloadly](https://sideloadly.io/)，连接 iPhone。
2. 拖入 `PhotoDesk-unsigned.ipa`，填 Apple ID，Start；Bundle ID 保持 `com.example.PhotoDesk` 不改。

### SHA256 校验（可选但建议）
```
Windows:  certutil -hashfile PhotoDesk-unsigned.ipa SHA256
macOS/Linux:  shasum -a 256 PhotoDesk-unsigned.ipa
```
与 `PhotoDesk-unsigned.ipa.sha256` 内容比对一致再安装。

### 续签
免费账号 7 天后过期：手机与电脑同一 Wi-Fi 且 AltServer 运行时，AltStore 会自动后台续签；数据不丢失。签名失败时记录 AltStore 报错码与版本（不归因于代码）。

## 4. 下载 IPA

```
gh run download <RUN_ID> -n PhotoDesk-unsigned-ipa -D artifacts/ipa
# 或浏览器：GitHub 仓库 → Actions → 对应 run → Artifacts → PhotoDesk-unsigned-ipa
```
（R 系列对应的功能在 CI 模拟器已由单元/UI 测试覆盖的部分见 docs/11；本清单只列模拟器无法覆盖的真机项。）

## 5. 已知边界（验收时留意）

- 系统删除确认**每批一次**（5,000/批），无法为零——iOS 安全边界，详见 已知问题.md §13。
- 免费 Apple ID 签名 7 天过期，AltStore 自动续签；过期后 App 打不开，续签即恢复（数据不丢）。
- 模拟器验证记录（CI）见 docs/11；本表为唯一真机证据来源。
