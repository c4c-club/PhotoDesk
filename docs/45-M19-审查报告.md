## 3. 可行性结论（答 docs/41 §7 十问）

1. **唯一写入口保留？** 是。`applySelectionChanges`（`LibraryViewController.swift:1008-1028`）是选中集唯一写入口；M19 只改命中层（rowBandHitProvider 产出 [IndexPath] → `dataSource.itemIdentifier` → assetID 序列），写入口与 `SelectionState.applyDelta` 通道不动。
2. **行带几何可从缓存推？** 可以。`GridHitTester.ensureCache`（`GridHitTester.swift:60-90`）已缓存真实 layoutAttributes（firstRowMinY/rowHeight/headerNaturalMinY，rowHeight=次行 minY−首行 minY 实测）；RowBandMap 由该缓存构造、随 invalidateGeometry 失效。禁止 DSSpacing 推算（不变量 8）。
3. **跨 section 平铺？** 平铺序 = section 升序 → row 升序（RowBandMap.init 平铺，跳空段）；跨月拖动=整段覆盖（行为表 #7）；单月 scope 过滤在位（B4：`LibrarySelectionController.swift:279`）。
4. **末行/单列/空段/粘性头边界？** 末行只展开真实 item（`row*cols..<min((row+1)*cols,itemCount)`）；单列段 `probeColumns` 已回退 columns=1；空段平铺时跳过；粘性头 clipTop=视口顶+头高，被完全遮挡行不可命中，钳到头下缘最近可见行（`bandIndex(atContentY:clipTop:)`；遮挡先例 `LibraryGridGeometryTests` H1 与 UI :673）。
5. **起点在空白？** 双闸现状满足，零改动：`handleTouchDown` hitID guard + `gestureRecognizerShouldBegin` 要求 `indexPathForItem(at:) != nil`（`LibrarySelectionController.swift:541-555`）。
6. **回滑保 base？** `SlideSelectTrail(base: selectedIDsProvider(), anchorInitiallySelected:, scope:)` 已在 beginTrail 构造（`LibrarySelectionController.swift:436-438`）：手势前已选入 base，回滑按行带出栈、退到 base 之下不再减少；anchorInitiallySelected 使起手已选格进入取消模式。行带语义只改命中单元粒度，trail 累积/撤销机制不变。
7. **状态机已支持长按后纵拖？** 是。长按 0.28s→armed→任意方向拖（pan maximumNumberOfTouches=1）→dragging；未长按纵拖→releaseScroll 继续滚动。M19 零状态机改动。
8. **5 条冲突用例怎么改？**（T06 执行）：③ :405「右列不得入选」→「右列下滑整行全选 + 相邻行带不得入选」；④ :453 斜拖走廊断言（36pt 容差）→「斜拖按经过行带序列入选，未经过行带不入选，不补矩形」；⑥ :592 预选保持→断言集合按行带重算；⑩ :713「取消数=同列可见格数」→「回滑取消按整行带计（行数×列数）」；⑬ :804 横拖→整行入选。探针转正：actual == 3×columns。
9. **2 万张性能预算？** 行带解析 O(log n)+O(1) ≤2ms；展开+applyDelta O(delta) ≤4ms（A09：全选 2 万张单帧 <4ms 在案）；≥55FPS、<250MB。T07 实测，不达标才启用 `rowBandMaxExpandPerFrame`（docs/42 §10.2）。
10. **Release 1.8.0 (9) 谁产出？** CI `macos-15` build job 既有未签名 ipa 步骤（`CODE_SIGNING_ALLOWED=NO` → `build/PhotoDesk-unsigned.ipa` + sha256）；T10 抬版本后 workflow_dispatch 派发，Windows 端 AltServer 签名装真机；真机未接入或签名不可用 → progress 写 BLOCKED，仍交付 ipa 绝对路径+SHA256。
