-------------------- 用户原文 6 条硬约束（逐字，不得删减、不得改写）--------------------
① 手势配置：添加一个 UIPanGestureRecognizer，设置 maximumNumberOfTouches = 1，并设置 cancelsTouchesInView = false，确保不会吞掉轻点事件。手势的 delegate 必须实现 gestureRecognizerShouldBegin 和 gestureRecognizer(_:shouldRecognizeSimultaneouslyWith:)，以便在非选择模式下让 CollectionView 正常滚动。
② 方向锁定（关键）：在 .began 状态先记录起始点，在 .changed 状态比较累计位移。只有水平位移绝对值大于垂直位移绝对值时，才将 isDragSelecting 置为 true 并开始执行选择逻辑；如果垂直位移占优，手势应让位给 CollectionView 的纵向滚动，isDragSelecting 保持 false，直到手势结束都不再激活选择。不要在 .began 就贸然激活，否则纵向滚动会被打断。
③ 状态快照（实现往返恢复的关键）：在 isDragSelecting 首次变为 true 的那一刻，对当前 CollectionView 的选中状态做一次快照。用一个 [IndexPath: Bool] 字典（或 Set<IndexPath> 记录「开始时已选中」的集合）保存每个 cell 在滑动开始前的原始选中状态。后续手指经过某个 cell 时：如果该 cell 在快照中，恢复为快照中的值；如果该 cell 不在快照中（滑动开始时未选中），则设为 true。这样就能天然支持「反向滑回时取消选中」，且不会错误地取消掉滑动开始前就已经选中的 cell。
④ indexPath 追踪与去重：在 .changed 中通过 collectionView.indexPathForItem(at: location) 获取手指下的 indexPath。维护一个 lastProcessedIndexPath，只有当前 indexPath 与上一次不同时才执行状态更新，避免同一 cell 被重复处理导致状态闪烁。
⑤ 滚动协同：isDragSelecting == true 期间，将 collectionView.isScrollEnabled 设为 false；手势进入 .ended / .cancelled 后立即恢复为 true，并清空快照和 isDragSelecting 标记。
⑥ 边缘自动滚动（必须实现）：当手指的 y 坐标进入 CollectionView 可见区域的顶部或底部缓冲区（建议 60pt）时，启动一个 CADisplayLink，根据手指距边缘的距离计算滚动速度，逐帧修改 contentOffset，使屏幕外的 cell 也能被滑过选中。手指离开缓冲区或手势结束时，销毁 CADisplayLink。
--------------------------------------------------------------------------------

逐条落地与对应测试：
- ① `setupSelection()` 移除 `UILongPressGestureRecognizer`，新增 `slideSelectPan`：`maximumNumberOfTouches = 1`、`cancelsTouchesInView = false`、`delegate = self`；`gestureRecognizerShouldBegin` 在非选择模式 / 双指 / 缩放事务期返回 false；`gestureRecognizer(_:shouldRecognizeSimultaneouslyWith:)` 对 CollectionView 自身 `panGestureRecognizer` 返回 true（非选择模式让位），对 `UIPinchGestureRecognizer` / `numberOfTouches >= 2` 返回 false。测试：`testTapNotSwallowedBySlidePan`、保留 `PageRegressionUITests.swift:228-240` `testScrollWorksInSelectionMode`、双指捏合列数仍可用。
- ② `.began` 只记 `dragStartPoint` + `verticalScrollLocked = false`；`.changed` 用 `translation(in: collectionView)` 的累计 `dx/dy`，仅当 `abs(dx) > abs(dy)` 首次置 `isDragSelecting = true`；`abs(dy) >= abs(dx)` 则 `verticalScrollLocked = true`，本手势余生不再激活；**严禁 .began 激活**。测试：Core `SlideSelectPolicy.shouldActivate` 单测 + UI `testVerticalDragDoesNotSelectAndScrolls`。
- ③ 激活那一帧用 `indexPathsForSelectedItems` + `selectionState` 构造 `[IndexPath: Bool]`（或 `Set<IndexPath>` originallySelected）；经过 cell 时 `target = snapshot[ip] ?? true`；同步 `selectionState`、`collectionView.selectItem/deselectItem`、`reloadSelectionBadges`、`updateSelectionCount`。测试：Core `resolvedSelection` 单测 + UI `testDragBackRestoresOriginal`、`testOriginallySelectedNotCleared`。
- ④ `.changed` 用 `indexPathForItem(at: location)`（location 需 `convert` 到 collectionView 坐标）；`lastProcessedIndexPath` 去重；同一 ip 不重复写。测试：`testNoFlickerOnSameCell`（AX 值稳定）+ 去重计数单测。
- ⑤ `isDragSelecting` 置 true 时 `collectionView.isScrollEnabled = false`；`.ended/.cancelled/.failed` 统一 `finishSlideSelection()`：恢复 `true`、`snapshot.removeAll()`、`isDragSelecting = false`、`lastProcessedIndexPath = nil`、`verticalScrollLocked = false`、销毁 displayLink。测试：`testScrollEnabledRestoredAfterDragEnd`。
- ⑥ `SlideSelectConfig.edgeBuffer = 60`；`CADisplayLink` 加 `.common`；每帧按 `distanceToEdge / edgeBuffer` 映射带符号速度（`minStep...maxStep`，越靠边越快，顶/底决定方向），`contentOffset.y` 钳制在 `[-adjustedTop, maxBottom]`，逐帧 `setContentOffset(animated:false)`；滚动后**重新**用当前手指 location 求 `indexPathForItem` 并走 ③④，使屏幕外 cell 也被滑过选中；离开缓冲区或手势结束 `invalidate()` 并置 nil。测试：Core `edgeVelocity` / `clampedOffset` 单测 + UI `testEdgeAutoScrollSelectsOffscreenCells`（改写 `testBoxAutoScrollSelectsWhileScrolling`）。

必须清理：`UILongPressGestureRecognizer`、`onBoxLongPress`、`updateBoxSelection`、`visibleCellRectsInViewCoordinates`、`selectionOverlay` 框选视图、`startBoxAutoScroll` / `boxAutoScrollTick` 的框选实现，不留不可达死代码。**保留**：`selectionBar`、`SelectionState`、`PhotoGridCell` 徽标 / 边框 / DEBUG `accessibilityValue`、批量动作（收藏 / 移到最近删除 / 隐藏）、单月 scope、点选切换、`allowsSelection`。`PhotoDeskCore` 的 `GridHitRegion` / `BoxSelectConfig` 若零调用点可保留为 Foundation 通用工具但不得再被多选引用，其既有 15 条单测**不得删除**。
必须下沉 Core（零 Apple import）：新增 `PhotoDeskCore/Sources/PhotoDeskCore/SlideSelectConfig.swift`（`edgeBuffer = 60`、`minStep`、`maxStep`、`directionLockEpsilon` 等全部收口，禁止 VC 散落数字）与 `SlideSelectPolicy.swift`（`shouldActivate(dx:dy:wasLocked:)`、`resolvedSelection(originallySelected:visited:)`、`edgeVelocity(...)`、`clampedOffset(...)`，纯 `Double` / 自定义值类型，禁止 `CGPoint/CGRect/UIImage/PHAsset`，`IndexPath` 也统一用 `SlideSelectCell(section:Int, item:Int)` 值类型适配）；新增 `PhotoDeskCoreTests/SlideSelectPolicyTests.swift`。App 侧新增 `PhotoDesk/Features/Library/SlideSelectGestureController.swift`（`@MainActor`，顶部 `// MARK: - 职责说明`，由 XcodeGen 自动进 target），只做映射不重写判定。
