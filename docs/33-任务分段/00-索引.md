## 执行协议（每任务都适用）

1. `git status --short`；确认上一任务在 `artifacts/plan/progress-m17.md` 为 DONE。
2. 只读当前任务卡 + 它指定的 docs/31、docs/32 小节 + 卡内列出的源码文件。
3. 先写**红测试**（Core 单测或 UI 用例），确认失败；再改实现。
4. 跑本卡门禁；本机不能编译就推 CI 等真实结果，禁止编造。
5. 按卡内要求提交 git（先 test，后 fix）。
6. 更新 `artifacts/plan/progress-m17.md`（状态/提交号/测试数字/证据路径）。
7. 只输出一句交接：下一个任务文件名。
