## 3. 步骤

1. 新增 `MarqueeHitResolver.swift`：
   ```swift
   public struct CellFrame: Hashable, Sendable { public let id: String; public let minX, minY, maxX, maxY: Double }
   public struct HitRect: Equatable, Sendable { public let minX, minY, maxX, maxY: Double
       public init(anchor: (Double, Double), current: (Double, Double))  // 自动归一 + 1pt 扩展
   }
   public enum MarqueeHitResolver {
       public static func hit(_ rect: HitRect, cells: [CellFrame], clipTop: Double? = nil) -> Set<String>
   }
   ```
   - 相交判定：`cell.minX <= rect.maxX && cell.maxX >= rect.minX && cell.minY <= rect.maxY && cell.maxY >= rect.minY`
   - `clipTop` 非 nil 时先把矩形上边抬到 `clipTop`（粘性头裁剪），抬后为空则返回空集
   - 非有限值/空数组 → 空集；`cells` 允许未排序
2. 单元测试 ≥ 20：空、单点、1pt、部分相交、包含、被包含、跨段、同 id 重复、`clipTop` 裁掉一半、`clipTop` 全裁、矩形反向拖、2 万个 frame 性能 < 5ms。
3. 在 `MarqueeSelectionPolicy` 顶部加注释：`@available(*, deprecated, message: "T04 完成后删除；命中一律走 MarqueeHitResolver + 真实 layoutAttributes")`，本任务不删（避免一次改太多）。
