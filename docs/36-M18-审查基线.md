## 0. 本轮的最高约束

1. 交互：**轨迹滑选（trail/path selection）**，不是矩形 marquee，不是整行带，不是 visited 奇偶 toggle。
2. 命中：相邻采样点组成的**线段**与真实 cell frame 求交，返回有序 id；不是「按下点→当前点」矩形。
3. 集合：`base + 路径栈`；回滑按栈截断，只撤销本次手势产生的变化；手势前已选 cell 不得受影响。
4. 滚动：用户明确「允许滚动」；执行时不得退回双指专属规则，也不得再次用 `minimumNumberOfTouches = 2` 劫持单指。
5. 基线：iOS 16.0；不用 iOS 17+ API，不写双实现；`PhotoDeskCore` 只 `import Foundation`。
6. 交付：分段执行、合适节点本地 git 提交、CI 模拟器测试、真机/AltServer 实测（设备未接入写 BLOCKED，不伪造）、Release 未签名 IPA、汇报绝对路径与 SHA256。
