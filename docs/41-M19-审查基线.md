## 3. 为什么「必须每一张都摸到」是链路的必然结果

1. `GridHitTester.hitTestLine` 只把**线段外接矩形内**的 cell 交给 `TrailHitResolver`；
2. `TrailHitResolver` 再用 `Liang–Barsky` 判定「线段是否穿过该 cell 的矩形」，只有穿过才命中；
3. 手指沿右列竖直下滑时，线段宽度≈1pt，只穿过右列 cell —— 左列 cell 的矩形与线段不相交，**永远不会命中**；
4. `SlideSelectTrail` 收到的是「右列那几个 id」，回滑也只按这些 id 出栈。
→ 所以这是**命中粒度**问题，不是灵敏度/阈值问题；调 `hitExpansion` 只会让相邻格粘边，不会变成整行。
