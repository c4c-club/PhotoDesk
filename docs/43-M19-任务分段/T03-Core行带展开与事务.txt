## 0. 目标

把「行带下标序列」展开成**有序 item 序列**，并与既有 `SlideSelectTrail` 组合，证明：正向整行加选、回滑整行撤销、预选不受影响、取消模式整行恢复。

## 1. 只读范围

- `PhotoDeskCore/Sources/PhotoDeskCore/RowBandMap.swift`（T02 产物）
- `PhotoDeskCore/Sources/PhotoDeskCore/SlideSelectTrail.swift`
- `PhotoDeskCore/Tests/PhotoDeskCoreTests/SlideSelectTrailTests.swift`

## 2. 步骤

1. 红测试 `RowBandTrailTests.swift`（≥10 条）：
   - 行带 0..2 × 3 列 → 展开 9 个 item，行主序；
   - 末行不满 → 只展开实际 item；
   - `bandSequence` 反向 → 展开顺序反向（供回滑截断）；
   - 与 `SlideSelectTrail` 组合：正向选 3 行后 target = 9 格；回滑到第 1 行后 target = 3 格；再正向回到第 3 行恢复 9 格；
   - 预选 X（不在路径行内）全程保持；预选 Y（在路径行内、base 已含）回滑后仍保持；
   - deselect 模式：从已选行起拖，滑过 2 行后移除对应格，回滑恢复；
   - scope 过滤：行带含 scope 外 item 时不展开；
   - 10k item 全库扫一遍展开 + consume <10ms。
2. 跑 Core 得真实编译失败/断言失败，归档 `artifacts/audit/m19/t03/red.log`；提交红测试。
3. 新增 `PhotoDeskCore/Sources/PhotoDeskCore/RowBandItem.swift` + `RowBandExpander.swift`：
   - `RowBandItem(section:item:)`（`Hashable/Sendable`）
   - `RowBandExpander.items(bandIndices:in map:) -> [RowBandItem]`：行序 + 行内列序；去重保序。
   - `RowBandExpander.orderedIDs(bandIndices:in map:scope:resolve:) -> [String]`（`resolve` 为 App 注入的 `(RowBandItem) -> String?` 闭包；Core 不做 id 映射）。
   - scope 过滤放在展开阶段（不是事后 intersection）。
