## 2. 步骤

1. 红（Core）：补 `RowBandTrailTests` 6 条边界：
   - 回滑跨 section（从第 2 月回滑到第 1 月末行）整段撤销；
   - 取消模式下「base 只含整行中的部分格」→ 滑过该行只移除 base 内格，不新增；
   - 「起手行已全选」→ deselect 模式，滑过回滑后整行恢复；
   - scope = 单月时，跨月行带只展开当月 item；
   - 全选（scope 全量）后行带取消 → 只减对应行；
   - `bandSequence` 在同一行内抖动 → 展开幂等。
2. 红（UI）：新增 3 条用例（可先放 `SlideSelectTrailUITests` 末尾，T08 统一整理）：
   - 右列长按下拖 3 行 → 计数 = 3 × columns（精确，非 ≥）；
   - 回滑 2 行 → 计数回到 1 行；
   - 从已选格起手下滑 2 行 → 整 2 行取消，回滑恢复。
   推 CI 定向，记录真实失败（当前实现必然失败：只选右列）；提交红。
3. 按失败修 Core/App；每轮记录 run id + 失败断言原文。
4. 全绿后把三条 UI 用例纳入正式套件（T08 再整体去重）。
5. 更新 `docs/05`、`progress-m19`：T06 DONE。

## 3. 验收

- 六条 Core 边界 + 三条 UI 用例全绿；计数断言必须是「行数 × 列数」而不是范围。
- 预选格与手势前已选行在任何回滑路径下都不丢。
- 单月 scope 下跨月拖动不得越界选中。
