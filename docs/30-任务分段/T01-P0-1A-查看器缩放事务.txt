2. 先写红测试：PhotoDeskCore 的 ZoomTransformTests（至少 20 条：NaN、Infinity、0 bounds、scale 0、min/max、焦点缩放、边界平移、幂等）；iOS 的 ZoomableImageCellTests（非法 transform 复位、reuse 复位、动画 token、零 bounds）。
3. 确认新测试在旧实现上失败或无法编译；记录失败输出到 artifacts/audit/2026-11-12/red-viewer.txt。

7. 改 ViewerViewController：缩放手势/动画/未 settled 时禁止翻页、删除、dismiss、批量 reload；只允许当前活跃 cell 接收 transform。
8. 补 UI 测试：500 轮捏合；双击放大动画中立即捏合；min/max；三指；旋转后捏合；翻页复用后捏合；前后台切换后捏合。
9. 跑 scripts/test-core.ps1；推送并跑 CI 定向测试：PhotoDeskTests/ZoomableImageCellTests + PhotoDeskUITests/ZoomStabilityUITests；把 run id 写入 progress。
10. 提交：先 test(viewer) 红测试，再 fix(viewer) 实现；不要把红测试和修复混在一个提交。
