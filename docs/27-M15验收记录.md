## 2. 四项 P0 结构性重做（docs/25 §2 全新审查 → §4/§5/§6）

### P0-1 捏合缩小/放大必崩溃（缩放重做）
- **根因**（25 份 .ips 全指向）：崩溃栈 25/25 `EXC_BAD_ACCESS` → `_zoomScaleFromPresentationLayer + _getDelegateZoomView + appendInterpolation + swift_dynamicCast`，16/25 显式 `viewForZooming` 入栈。旧实现把 UIScrollView zoom delegate、contentSize/contentInset 写回、configure/layout 多路写几何混在一个复用 cell 上，presentationLayer 读取与 delegate 摘除竞态。
- **重做**：cell v6 全重写——`viewportScrollView` 降级为**纯容器**（isScrollEnabled=false、delegate=nil、min=max zoom=1，**永不调用任何 UIScrollView zoom API**）；几何全部走 `PhotoDeskCore.ZoomTransformPolicy`（pinch/pan/doubleTap/relayout + clampTranslation，纯函数）；手势状态机 `ZoomInteractionController`（Phase idle/pinching/panning/settling/animating）；`ViewerGesturePolicy` 保留为纯值判定器（isZooming/宽限窗口/删除互斥）。全仓 `viewForZooming` / `UIScrollViewDelegate` / `setZoomScale` / `contentInset` / `zoomContentView` 0 命中（红线）。
- **CI 实锤修复**（并入本 P0 的真实缺陷）：手势门禁在图片晚到时永不生效（setGesturesEnabled 不重估）；根视图占位双击 + chrome tap 互斥杀死 cell 双击；程序性 reset 污染宽限窗口。分别以 setGesturesEnabled 即时重估、删根双击、lastActivity 仅用户手势路径修复（提交 787d9e0 / 0582030 / 0a34fb7）。
- **证据**：Core ZoomTransformPolicyTests 25 条 + cell/控制器单测 20 条 + ZoomStabilityUITests 10 条（500 轮捏合压力、翻页/复用/旋转后捏合、双击循环、删除互斥、放大平移不翻页）。

### P0-2 上次浏览位置记不准（位置记忆 v5）
- **根因**：v4 的 UserDefaults 存储 + 多状态机（快照/布局/验证三态机与保存门禁脱节）+ 整行语义误差，恢复成败是概率事件。
- **重做**：schema **v5**（queryKey 盖章、Application Support `anchors-v5.json` 原子文件、容量 64 淘汰）；单一 `PositionRestoreMachineV5`（idle/restoring/applying/verifying/settled/fallback，**canSave 只在 settled**=I1）；恢复算法 scrollToItem(.top) → target=minY−visualY → 钳制 → verify ±0.5pt → 一次 offset 重试 → fallback（section/ratio）。
- **CI 实锤修复**：① 保存发生在月份跳转的估算布局落点（off 13208 vs 真实 12688，−520pt 确定性漂移）→ 月跳保存移到 `verifyJumpLanding` 钉住线复核收敛后（cda611e）；② 拖动减速结束回调与 terminate 竞速 → restSaveWorkItem 静止补存（8e082c6）；③ 恢复期间登记的前插补偿在 settle 后把精确位置拖走 → apply 登记 guard + settle 清任务（0582030）。
- **证据**：PositionRestoreUITests **testColdLaunchRestoresSamePixelPosition10Times ✅（10 轮冷启动同 anchor ±2pt）**、testForceKillRestores ✅、testBackgroundForegroundRestores ✅、testRotationKeepsAnchor ✅、testFilterSwitchDoesNotLeakAnchor ✅、testMonthJumpPersistsAfterRelaunch ✅；Core 状态机/锚点/文件存储 43 条。

### P0-3 滑动多选左侧向下滑选中整行（框选重做）
- **根因**：旧 `SlideSelectRangePolicy` 的"整行带"语义（起点行+方向决定整行带，垂直下拉必然带走同行其它列）。
- **重做**：`PhotoDeskCore.MarqueeSelectionPolicy`（矩形相交：行候选 floor 推进逐行精确测试、间隙不命中、宽/高<1 扩 1pt）；控制器重写为纯矩形语义（起点 content 坐标固定，自动滚动逐帧重算）；deselect 模式=锚点已选。
- **证据**：Core 26 条策略测试；MarqueeSelectionUITests 9 条（左列竖直只选中列、取消模式、回拖收缩、斜向、自动滚动、轻点不吞、全选取消、跨月）**全绿**；旧"整行"断言测试全部删除。

### P0-4 多选后无法滑动取消（同一重做覆盖）
- 取消模式（从已选格起拖 → 矩形命中从选中集移除）+ 边缘自动滚动方向记忆（hold 阶段无 .changed 采样时的方向续滚）。
- **证据**：testDragFromSelectedCellDeselects ✅（首列 6 格取消 3 格精确断言）、testDragBackShrinksWithinSameGesture ✅、testEdgeAutoScrollSelectsOffscreenCells ✅ / testAutoScrollMarquee ✅（屏内跨度上限 5，count≥6 证明屏外格入集——初版 ≥8 标定过高已修正并注明）。
