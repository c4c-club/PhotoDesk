## 2. 步骤

1. 红：扩写 `LibraryGridGeometryTests.swift`：
   - 2/3/4/5 列 × `contentOffset.y ∈ {0, 2000, 8000, 20000}`，断言 `hitTestLine` 结果 == 手工按 `layoutAttributesForItem` 求交并按 `tMin` 排序的 IndexPath 序列。

2. 推 CI 定向 `PhotoDeskTests/LibraryGridGeometryTests` 拿红证据；每条失败附 run id / 截图附件路径；提交红测试。
3. 按真实失败修 `GridHitTester`：
   - 候选行/列枚举必须来自真实 attributes，不得用 `DSSpacing` 推算。
   - 线段外接矩形只用于**缩小候选集**，最终顺序与命中一律由 `TrailHitResolver` 决定。
   - `clipTop` 仍为「视口顶 + 钉住头高」；头下被遮住的 cell 不得入栈。
   - 自动滚动 `setContentOffset` 前后同一窗口坐标换算，内容流过方向 `before→after`；`SlideSelectPolicy.clampedOffset` 保持。
   - `LibraryGridGeometryTests` 全部迁到 `hitTestLine` 后，**物理删除** `GridHitTester.hitTest(rectInContent:)`；`audit-m18.ps1 -Strict` 的矩形残留类 BLOCKING 必须归零，日志存 `artifacts/audit/m18/t07/green.md`。
4. 触觉：`pendingSelectionHaptic` 只在 `SlideSelectDelta.isEmpty == false` 置位；机器 `hapticMinInterval=0.06` 节流保持；DEBUG `debugHapticCount` 断言 ≤16 次/秒。
5. 跑：Docker `scripts/test-core.ps1`；CI 定向单测 + `PerformanceUITests`；记录帧预算（拖动一帧 ≤4ms / 滚动 ≥55FPS / 内存 <250MB）。
6. 更新 docs/05、progress-m18：T07 DONE。
