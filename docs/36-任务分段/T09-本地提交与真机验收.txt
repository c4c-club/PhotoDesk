## 1. 步骤

1. 本地检查：
   - `git status --short`；`git log --oneline -20`；列出 T01–T08 每个提交号并写入 `artifacts/plan/progress-m18.md`。
   - `git diff --stat HEAD~1..HEAD` 确认没有意外二进制/截图入库；未追踪证据目录按 `.gitignore` 规则处理。
   - 跑 `scripts/test-core.ps1` 最终 Core 数；`scripts/audit-m18.ps1 -Strict` 输出 0 blocking（T08 后的 UI 改名也算进脚本）。
2. 取包：
   - 从 T08 最终绿 CI run 下载 `PhotoDesk-unsigned-ipa` artifact；若尚未是 1.7.0，先用当前版本做真机交互验证并在进度表注明「版本号待 T10 变更」。
   - 校验 `Payload/PhotoDesk.app/Info.plist` 的 `MinimumOSVersion=16.0`；记录 SHA256 与来源 run id。
3. 真机通道（Windows）：
   - 探测 AltServer / AltStore / iPhone 是否接入；按 `安装说明.md` / `docs/06 §7.4` 用 AltServer 对未签名 IPA 签名安装（免费账号 7 天）。
   - 若不可用：在 `docs/39` 写 **BLOCKED**，逐条列出未执行项，不得用模拟器结果冒充真机。
4. 12 条真机清单（逐条写 PASS/FAIL/BLOCKED + 现象）：
   - ① 安装与首启授权 ② 长按进入多选 ③ 轨迹滑选到哪选到哪 ④ 斜拖不补全矩形 ⑤ `A→B→C→B` 回滑取消 ⑥ 起手已选取消 + 回滑恢复 ⑦ 单指纵向滚动计数不变 ⑧ 底缘自动滚动连续入集 ⑨ 跨月份/粘性头不误选 ⑩ 全选后轨迹取消 + 单月 scope ⑪ 退出多选复位 ⑫ 深色模式/VoiceOver/连续 10 次手势。
5. 真机发现缺陷：回到对应任务卡范围开 `fix(selection): <真机缺陷>` 提交，重跑最小 CI；不得在验收记录里只写「已优化」。
6. 更新 `docs/05`、`artifacts/plan/progress-m18.md`：T09 DONE 或 BLOCKED（等真机）；`docs/39` 写验收记录初稿。
