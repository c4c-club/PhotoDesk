## 0. 目标

在 `PhotoDeskCore` 新增 `SlideSelectTrail`：手势基线快照 + 路径栈截断，输出 O(delta) 的 `add/remove`。**不碰 UIKit、不碰 App**。

## 2. 步骤

1. 先写 `PhotoDeskCore/Tests/PhotoDeskCoreTests/SlideSelectTrailTests.swift` 红用例（≥14 条）：
   - select 正向 `A→B→C`；`A→B→C→B` 回滑；回跳到更早节点；`A→B→A→B` 净 delta；同一 id 抖动幂等；空输入幂等。
   - base 保护：手势前已选 X 不受 path 出栈影响；deselect 模式回滑恢复 base 内 cell。
   - `anchorInitiallySelected=true/false` 模式分叉；`base` 已含 anchor 仍正确。
   - scope 外 id 忽略；空 id 忽略；重复 id 折叠；`target` 与逐帧 delta 累加一致。
   - 10k 步 consume <5ms（用 `measure` 或时间戳；CI 容器预算单独记录）。
2. 跑 `scripts/test-core.ps1` 拿到**真实编译失败**（`cannot find SlideSelectTrail`），日志存 `artifacts/audit/m18/t02/red-compile-failure.log`，单独提交红测试。
3. 新增 `PhotoDeskCore/Sources/PhotoDeskCore/SlideSelectTrail.swift`：
   - `public enum SlideSelectMode { case select, deselect }`
   - `public struct SlideSelectDelta { add/remove: Set<String>; isEmpty }`
   - `public struct SlideSelectTrail`：`base`、`scope`、`mode`、`target`、`path: [String]`、`occurrences: [String:[Int]]`。
   - `init(base:anchorInitiallySelected:scope:)`：`base` 先与 scope 取交集；`mode` 由 `anchorInitiallySelected` 决定。
   - `mutating func consume(_ orderedIDs: [String]) -> SlideSelectDelta`：按 `docs/38 §2.3` 实现；同帧 delta 净抵消；`consume([])` 不改状态。
   - 文件顶部 `// MARK: - 职责说明`；只 `import Foundation`；无魔法数（阈值来自 `SlideSelectConfig` 或无阈值）。
4. 跑 `scripts/test-core.ps1` 全绿；记录总数/失败数；推一次 CI core-linux 复验（Linux Foundation 与 Darwin 差异由 CI 兜底）。
5. 更新 `docs/05` 变更日志、`artifacts/plan/progress-m18.md`：T02 DONE（红/绿日志 + run id）。
