# T05 — App 线段命中与路径增量接线

> 自包含任务卡。只读本文件 + `docs/37 §1/§4/§5/§7` + `docs/38 §2/§3`。

## 0. 目标

把 App 三处核心链路从「矩形 + base∪rect」换成「线段 + 路径事务 + 增量 delta」；恢复 App 可编译。允许滚动保持 T04 仲裁状态表。

## 2. 步骤

1. 红测试（App 单测层）：在 `PhotoDeskTests` 新增/改写 2 条真布局测试，断言 `GridHitTester.hitTestLine(from:to:)` 存在且返回有序 IndexPath；本机不能编译，用 GitHub Actions 定向 `LibraryGridGeometryTests` 拿真实编译失败 log，存 `artifacts/ci-evidence/m18-t05/<run-id>/red.log`；提交红测试。
2. `GridHitTester.swift`：
   - 保留 section 缓存、`probeColumns`、真实行高、二分、`invalidateGeometry()`、`lastQueryCount`、粘性头 `clipTop` 计算。
   - 新增 `func hitTestLine(from: CGPoint, to: CGPoint) -> [IndexPath]`：用现有候选段/行枚举收集与「线段外接矩形」相交的 cell frame，转 `[CellFrame]`，调 `TrailHitResolver.orderedIDs`，按 id 映射回 IndexPath；`clipTop` 传现有粘性头下缘。
   - 旧 `hitTest(rectInContent:)` 本卡先保留标 deprecated（T06 删），避免一次改动过大；但生产调用必须切到新接口。
   - 查询数仍 ≤60/热帧；不得遍历全部 section。
3. `LibrarySelectionController.swift`：
   - 删 `hitTestProvider(CGRect)`、`applyTargetIDs(Set)`、`lastTargetIDs`、`applyWindowSkips`、`processFinger()`、`currentMarqueeRect()`、`overlayFrame(for:)`、`onMarqueeRectChanged`、`overlayView` 的矩形驱动（视觉文件 T06 删）。
   - 新增 `trailHitProvider: (CGPoint, CGPoint) -> [String]`、`applySelectionDelta: (Set<String>, Set<String>) -> Void`、`private var trail: SlideSelectTrail?`、`lastTrailContentPoint: CGPoint?`、`anchorInitiallySelected: Bool`。
   - `handleTouchDown(.began)`：`anchorInitiallySelected = selectedIDsProvider().contains(hitID)`；`baseIDs` 不再在此拍。
   - `.beginTrail` effect：`enterSelection` 已执行完后 `base = selectedIDsProvider()`，构造 `SlideSelectTrail(base:anchorInitiallySelected:scope:)`，`consume([anchorID])` 落地；`lastTrailContentPoint = machine.pressPoint` 转 `CGPoint`；禁滚动与 `endTrail/releaseScroll` 成对。
   - `.updateTrail`：`processTrail(to: windowToContent(lastFingerWindowPoint))`；`delta.isEmpty` 直接返回，不触发触觉；变化才 `pendingSelectionHaptic = true` + `applySelectionDelta`。
   - `autoScrollTick`：`setContentOffset` 前取 `before = windowToContent(lastFingerWindowPoint)`，后取 `after = windowToContent(lastFingerWindowPoint)`，用 `before→after` 喂 `processTrail`，保证屏外内容按序入栈；`edgeVelocity/clampedOffset` 不动。
   - `finishSelection` / `endTrail`：销毁 `trail`、`lastTrailContentPoint`、displayLink；**不清空 `selectionState`**（退出多选由 VC 负责）。
   - `isConsumingTouch`、方向锁、`scrollStarted` 转发、`holdElapsed` 双通道、逐帧边缘监视保持不变。
4. `LibraryViewController.swift`：
   - 注入 `trailHitProvider`：`gridHitTester.hitTestLine(from:to:)` → `dataSource.itemIdentifier(for:)` → 有序 `[String]`（保持顺序、只过滤 nil）。
   - 注入 `applySelectionDelta`；把 `applySlideSelection(ids:)` 抽成 `applySelectionChanges(previous:current:)`：`SelectionState.applyDelta(add:remove:)` → 可见 cell diff → `updateSelectionCount()`（每帧写，仅 count 变化做 0.15s 过渡）。
   - 删除矩形 overlay 注入块（T06 清文件）；DEBUG `Library-DebugSummary` 的 `ovHidden/ovm/ovColor/ovFrame` 改为 `trailMode/trailPathCount/lastDelta` 取证字段。
   - 保留 `scrollViewWillBeginDragging` → `handleScrollStarted()`；`didSelectItemAt` 的 `isConsumingTouch` 闸门。
5. 推 CI 定向 `LibraryGridGeometryTests + SlideSelectTrailUITests尚未改名时的编译检查`；若 T08 未到，至少跑 `build` + 单测。记录真实 run id、失败→修复链，不得跳过。
6. 更新 docs/05、progress-m18：T05 DONE；写明 App 编译已恢复、矩形接口仅剩 deprecated。
