# docs/38 — M18 实施规划：原生轨迹滑选替换框选

> 状态：**规划，未实施**。本文件由 T01 全新审查后复核/修订；任何与 `docs/37-M18-审查报告.md` 冲突的地方，以 T01 实测结论为准并当场更新本文件。
> 用户语义：手指滑到哪就选到哪；往已选方向滑就取消；不要框选；允许滚动。
> 统一基线：iOS 16.0 / Swift 5.9+ / UIKit 网格 + Diffable / 0 三方依赖 / 0 网络 / `PhotoDeskCore` 零 Apple 依赖。

## 1. 目标交互与不变量

### 1.1 交互表

| 场景 | 目标行为 |
|---|---|
| 普通模式长按 0.28s | 进入多选并选中锚点，轻触觉；不弹菜单 |
| 长按不抬手继续拖 | 立即进入轨迹滑选，起点 = 按下点 cell |
| 多选模式在 cell 上起手横/斜拖 ≥8pt | 进入轨迹滑选，任意方向拐弯都跟手 |
| 多选模式单指纵向快速滑 | 允许滚动；不得误选；计数不变 |
| 滑到已选方向回滑 | 沿访问路径出栈，本次新增逐个取消；手势前已选保持 |
| 从已选 cell 起拖 | 取消模式：滑过取消；回滑恢复 |
| 拖到上下 60pt 边缘 | 自动滚动 2–12pt/帧，屏外 cell 按内容流过顺序入栈 |
| 抬手 | 保留最终选中；恢复滚动；销毁 displayLink/事务 |
| 点「完成」 | 清空选中与多选栏，恢复单指浏览 |

### 1.2 不变量

1. **不用矩形**：生产代码不得出现 `HitRect`、`hitTest(rectInContent:)`、`MarqueeSelectionPolicy.resolved`、`MarqueeOverlayView`、`Marquee-Overlay`、`lastMarqueeRect` 的活跃引用。
2. **不用整行带**：不得按 `row*columns..<(row+1)*columns` 补选同行。
3. **不用奇偶 toggle**：`A→B→A` 的结果必须是「A 保持模式初态，B 退出本次路径」，不是把 A toggle 回来。
4. **不用双指规则**：`minimumNumberOfTouches = 2` 在 `PhotoDesk/` 下 0 命中。
5. **不接管系统多选**：不启用 `collectionView(_:shouldBeginMultipleSelectionInteractionAt:)`；选中集合唯一事实源是 `SelectionState`。
6. **不破坏 AGENTS 红线**：删除仍走「移到最近删除」；Core 只 `import Foundation`；Feature 层不引用 `PHAsset`。
7. **iOS 16**：不引入 `@Observable`/`SwiftData`/`ContentUnavailableView`/`scrollTargetBehavior`，不写 `if #available(iOS 17, *)`。

## 2. 目标架构

```
UIKit 触摸
  ↓ LibrarySelectionController（事件映射；窗口坐标；CADisplayLink）
SelectionGestureMachine（状态/方向锁/触觉节流/边缘进出）
  ↓ trailHitProvider(from,to)
GridHitTester.hitTestLine(from:to:)（真实 layoutAttributes；粘性头裁剪）
  ↓ [CellFrame]
TrailHitResolver.orderedIDs（Core：线段扫掠，按进入 t 排序）
  ↓ [String] 有序
SlideSelectTrail.consume（Core：base + 路径栈 + scope；输出 delta）
  ↓ add/remove Set<String>
SelectionState.applyDelta → applySelectionChanges(previous:current:) → 可见 cell diff / 计数
```

### 2.1 手势仲裁（T01 定稿，docs/37 §3）

**保留方向锁，产品不改裁决**（T01 全新审查，当前源码行号见 docs/37 §3）：pressing 横向占优（|dx| > |dy|×1.2）进入轨迹滑选、纵向占优让位滚动（计数不变）、对角未决 ≤8pt 等待明朗；armed 起任意方向跟手；scrollStarted 任意阶段收尾落定路径事务；`minimumNumberOfTouches = 2` 永不出现（marqueePan/trailPan 单指，`maximumNumberOfTouches = 1`）。状态表：`idle → pressing → (横向/armed) → dragging ⇄ autoScrolling → ending → idle`，纵向让位回 idle。iOS 16.4 模拟器验证 = T08 UI 套件；真机 = T09。若 T08/T09 实测证明与「原生滑选任意方向」不可调和，必须在 `docs/37` 写明产品裁决，同步改本表、UI 测试、引导文案，并在 T08 重跑，不得静默改代码。

### 2.2 两个基线（实现红线）

- `anchorInitiallySelected`：在 **touchDown 帧**、`enterSelection` 之前，从当前 `selectedSet` 取；决定 select/deselect 模式。
- `base`：在 **beginTrail 帧**、`enterSelection(anchorID:)` 执行完之后拍；普通模式长按进入时 `base` 已含锚点。
- 二者混用会导致「长按第一张反而进入取消模式」。

### 2.3 路径事务语义

```text
path: [String] + occurrences[id]: [Int]
consume(orderedIDs):
  id == path.last                → 忽略抖动
  occurrences[id] 非空           → truncate(after: 最近一次出现)，出栈 cell 回到 base 状态
  否则                          → append，按 mode 改变 target
target = select ? base ∪ Set(path) : base − Set(path)
delta = target 相对上一帧的净 add/remove（同帧 A→B→A→B 相互抵消）
```

`consume([])` 必须幂等；快照 apply 窗口几何失效时**不保留上一帧矩形目标**，而是无操作，下一帧恢复。
