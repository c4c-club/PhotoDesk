## 1. 目标与验收场景（行为契约）

达到以下 10 条即视为「对齐 iOS 原生相册」：

| # | 场景 | 期望 |
|---|---|---|
| A1 | 普通模式长按任意缩略图（约 0.28s） | 进入多选；该图立即选中并出现角标；轻触觉；多选栏出现；不弹菜单 |
| A2 | 长按后不抬手继续拖动 | 连续框选，起点 = **按下点**（不是 10pt 之后的位置） |
| A3 | 多选模式单指上下滑 | 正常滚动；不选中任何 cell；不出现选框 |
| A4 | 多选模式单指从缩略图上横向/斜向拖 | 出现半透明选框，沿途 cell 实时加选（角标 + 轻微压暗 + 弹入动画） |
| A5 | 从**已选** cell 起拖 | 取消模式：选框描边变色、多选栏提示「取消选择中」、角标依次消失、计数递减 |
| A6 | 拖到屏幕上下边缘 | 60pt 边缘区内平滑自动滚动（2→12pt/帧），屏外 cell 持续入集；停止拖动即停 |
| A7 | 框选跨越 3 个以上月份分组 | 命中与手指矩形**逐格对齐**，粘性头下方不误选 |
| A8 | 滚动 3 屏后框选 | 命中仍逐格对齐（同一行相邻格不得被误选） |
| A9 | 全选 | 计数 = 当前筛选结果总数（不是已加载页数）；索引补齐后不丢选中 |
| A10 | 点「完成」/返回 | 多选栏收起、角标清除、单指滚动与点击浏览恢复 |

### 2.2 手势状态机（Core）

```swift
public enum SelectionGestureState: Equatable { case idle, pressing, armed, dragging, autoScrolling, ending }
public enum SelectionGestureEvent {
    case touchDown(point: CGPoint, hitID: String?)
    case holdElapsed
    case moved(dx: Double, dy: Double)
    case scrollStarted
    case ended
    case cancelled
}
public struct SelectionGestureConfig {
    var longPressDuration: TimeInterval = 0.28
    var allowableMovement: Double = 8
    var directionLockDistance: Double = 8
    var horizontalRatio: Double = 1.2
    var activationDistance: Double = 6
    var hapticMinInterval: TimeInterval = 0.06
}
```

状态迁移（全部单测覆盖）：

| 当前 | 事件 | 下一状态 | 副作用 |
|---|---|---|---|
| idle | touchDown(hit) | pressing | 记录按下点/锚点；启动 0.28s 计时 |
| pressing | holdElapsed | armed | 触觉 impact(.light)；进入多选并选中锚点；显示 0 尺寸选框 |
| pressing | moved 且横向占优 ≥8pt | dragging | 必要时先进入多选；锁定滚动 |
| pressing | moved 且纵向占优 | idle（失败） | 交还滚动，不进入多选 |
| pressing | ended < 0.28s | idle | 交给 tap（打开查看器/切换选中） |
| armed | moved | dragging | 框选开始 |
| dragging | moved | dragging | 重算命中 |
| dragging | 指尖进边缘区 | autoScrolling | 启动 display link |
| autoScrolling | 指尖离边缘 | dragging | 停止 display link |
| 任意 | ended/cancelled | ending → idle | 收尾：恢复滚动、隐藏选框、提交快照 |

### 2.3 手势仲裁（App 层）

| 识别器 | 配置 | 与其它识别器关系 |
|---|---|---|
| `UILongPressGestureRecognizer`（新增） | 0.28s，`allowableMovement = 8`，`cancelsTouchesInView = false` | 与 `marqueePan` 允许同时识别（长按定起点，pan 定移动）；进入 `armed` 后禁滚动 |
| `marqueePan`（新增，单指） | `maximumNumberOfTouches = 1`，方向锁 8pt | 与 scroll pan 允许同时识别；横向锁定后 `collectionView.isScrollEnabled = false`；纵向占优时主动 `.failed` |
| `collectionView.panGestureRecognizer` | **永远 `minimumNumberOfTouches = 1`**（删除现有双指规则） | 纵向拖动自然接管 |
| `UIPinchGestureRecognizer` | 不变 | 列数过渡期间冻结框选（沿用 `isGridLayoutTransition`） |

**关键不变量**：不得再通过修改 `minimumNumberOfTouches` 分离手势；只允许短暂 `isScrollEnabled = false` 并在收尾恢复。

### 2.4 命中几何（App 层）

`GridHitTester`：

1. **不重建网格**：删除 `itemSide/pitchY/sectionOriginY` 全部推算。
2. section 范围缓存：`sectionRange[i]` 由 `layoutAttributesForItem(at: IndexPath(item: 0 / count-1, section: i))` 得到；布局/snapshot/列数变化时失效。
3. 候选 section：二分查找与矩形相交的区间。
4. 行候选：由段内首行 attributes 得到真实 `rowHeight = 次行.minY − 首行.minY`，只枚举相交行。
5. 列命中：每行最多 `columns` 次 `layoutAttributesForItem(at:)`，用真实 `frame.intersects(rect)` 判定。
6. 可视区裁剪：矩形上边钳制到 `contentOffset.y + inset.top + 钉住头高度`（仅当该段头已钉住），避免选中被遮住的 cell。
7. 输出 `Set<IndexPath>` → VC 用 `dataSource.itemIdentifier(for:)` 映射 id（apply 窗口内不读数组）。
8. 复杂度 O(可见行 × 列) ≤ 60 次查询/帧，带 1 帧缓存；禁止遍历全部 section。

### 2.5 选中渲染（单一入口）

`PhotoGridCell.applySelection(isSelecting:isSelected:animated:)`：

| 元素 | 规格 |
|---|---|
| 角标 | 22pt 白圆 + `DSColor.tint` 勾，左上 4pt；`animated` 时 spring scale 0.6→1.0（0.18s，damping 0.7） |
| 压暗 | 选中覆盖 12% 黑（0.12s alpha 动画），未选中 0 |
| 边框 | 2pt `DSColor.tint`（保留） |
| 复用 | `prepareForReuse` 复位角标/dim/边框/动画 |
| AX | `accessibilityValue = "<assetID> selected/none"` 与视觉同源 |

`MarqueeOverlayView`：单层 CALayer，圆角 12，正常模式 `fill = tint 10%` / `stroke = tint 1.5pt`；取消模式 `fill = danger 8%` / `stroke = danger`；`isUserInteractionEnabled = false`；`accessibilityElementsHidden = true`。

### 2.6 选中一致性

| 规则 | 实现 |
|---|---|
| scope = 全量筛选结果 | `scope = Set(viewModel.filteredItems.map(\.id))`；快照回调用同一全量集合 `intersectScope` |
| 每帧只做增量 | `symmetricDifference` → `applyDelta(add:remove:)`；不再 `sorted()` 全量替换 |
| 计数 | 每帧写 `updateSelectionCount()`；仅 count 变化时数字过渡 0.15s |
| apply 窗口 | 几何查询 nil 时保留上一帧命中集合，不静默清空；下一帧重试 |
| 退出多选 | 复位 SelectionState/scopeID/标题/角标/覆盖层/`isScrollEnabled = true` |

### 2.7 性能预算

| 指标 | 预算 | 测量 |
|---|---|---|
| 框选每帧 | ≤ 4ms（iPhone 11 / 2 万张） | DEBUG p50/p95 输出 |
| 滚动帧率 | ≥ 55 FPS | `PerformanceUITests` |
| 内存峰值 | < 250MB | 现有门禁 |
| 触觉 | ≤ 16 次/秒 | 60ms 节流 |
| 布局查询 | ≤ 60 次/帧 | DEBUG 计数器 |

- `LibraryGridGeometryTests`（新增）：
  1. 真实 `LibraryGridLayout.make(columns:)` 建 `UICollectionView`（宽 390，2000 item / 40 段）；

  3. 断言 2/3/4/5 列下 `itemWidth == attributes.frame.width`（验证 H3）；

- `GridHitTesterMappingTests`：Mock dataSource（id = `a{section}-{item}`），断言矩形选中 `a3-7` 而非 `a3-6`。
