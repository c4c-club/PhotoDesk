## 1. 目标与非目标

### 1.1 目标

## 2. 统一语义合同

### 2.1 手势状态

SelectionGestureMachine 保持现有状态机，只改副作用载荷：

    idle → pressing → armed → dragging → ending → idle
    pressing --横向锁定--> dragging
    pressing --纵向占优--> idle + releaseScroll

- touchDown 记录 pressPoint / anchorID。
- holdElapsed：进入 armed，发 enterSelection(anchorID:) + beginTrail(anchorID:)。
- pressing 横向锁定：若未在多选，先发 enterSelection(anchorID:)；无论是否已多选，都发 beginTrail(anchorID:)。
- armed 后任意方向移动进入 dragging，发 updateTrail。
- 结束发 endTrail。

### 2.2 轨迹选择

SlideSelectTrail 继续作为唯一路径事务：

- 起手帧只 consume [anchorID]；不得用零长度行带查询替换为整行。
- 每个 processTrail 帧只 consume 该段有序命中 id。
- 回滑由路径栈截断实现；不要新增第二套选择集合。
- 行模式向下时，首次从 cells 进入 rows 先 rebase：base=当前选中集、mode 保留、path 清空并 consume 当前行完整 left-to-right 种子；随后只向路径追加尚未访问的 id。不得重喂已访问的起始行整行。
- 行模式向上时，优先 consume 目的行最后一个已访问 id，让路径栈回退；目的行不在路径中则退回 cell 线段命中。
- 选择模式由 anchorInitiallySelected 在 beginTrail 时固定；跨模式切换不得改变选择/取消方向。

### 2.3 命中模式

新增纯函数 SlideSelectPolicy.hitMode(dx:dy:fromBand:toBand:verticalDominanceRatio:)：

- fromBand == toBand → .cells。
- 不同 band 且 abs(dy) >= abs(dx) * ratio → .rows。
- 其余 → .cells。
- ratio 使用 SlideSelectConfig.rowBandVerticalRatio（建议 1.2），禁止散落魔法数字。
- 非有限输入 → .cells，保证安全降级。

这个判定按「当前帧线段」计算，不按整个手势起止点计算。因此「先横滑再下滑再左滑」会分别得到 cells / rows / cells 三种段模式。

### 2.4 4 列验收矩阵

以每行 4 张、至少 3 行为例：

| 步骤 | 期望 | 计数 |
|---|---|---|
| 长按 (1,1) | 只选 (1,1) | 1 |
| 右拖到 (1,4) | (1,1)…(1,4) | 4 |
| 下拖到 (2,4) | 第 1、2 行 | 8 |
| 下拖到 (3,4) | 第 1、2、3 行 | 12 |
| 左拖到 (3,2) | 第 1、2 行 + (3,1)(3,2) | 10 |

### 4.2 GridHitTester

文件：PhotoDesk/Features/Library/GridHitTester.swift

新增 GridTrailHit（App 层值类型）：

    struct GridTrailHit {
        let mode: SlideSelectHitMode
        let orderedIDs: [String]
        let rewindID: String?
    }

语义：

- .cells：orderedIDs 来自 hitTestLine(from:to:) 的按线段 tEnter 排序结果；零长度返回该点 cell（若有）。
- .rows 向下（toBand > fromBand）：
  - orderedIDs = RowBandMap.items(forBandIndices: fromBand...toBand) 的 id 展开，行主序；
  - rewindID = nil；
  - 控制器首次进入行模式（上一帧不是 rows）时先 rebase：用当前选中集作 base、保留 select/deselect 方向、清空 path，并 consume 当前行完整 left-to-right 作为种子；然后过滤 trail.path 中已存在的 id，再 consume 新行。
- .rows 向上（toBand < fromBand）：
  - rewindID = toBand 行最后一个 item 的 id；
  - orderedIDs = hitTestLine(from:to:) 的 fallback cell 序列；
  - 控制器若 trail.path 含 rewindID，只 consume [rewindID]；否则 consume fallback。
- fromBand/toBand 任一 nil → .cells fallback；不得返回整行。
- 旧 rowBandHitTest 可保留为内部 helper 或删除；生产路径必须切到 trailHitTest。若保留，必须标为 deprecated 且不再被 VC 引用。

关键不变量：

1. 长按起手绝不调用 trailHitTest；beginTrail 只 consume [anchor]。
2. 行向下不得把已访问行重复喂入；过滤器必须在 consume 前完成。
3. 行向上只用 rewindID 回退，不重喂目的行整行。
4. 行内列顺序固定为升序；横向 cells 顺序由 hitTestLine 的 tEnter 保证。
5. 跨 section 的 bandSequence 仍由 RowBandMap 平铺，不假设每段等行数。
