# T02 — 授权状态与刷新

> 依赖：T01。状态：⬜。预计：0.5d。
> 只读：00-索引、本卡、T01 的基线记录；可读 PhotoLibraryService.swift、LibraryViewModel.swift、LibraryContainer.swift 与对应测试。不要读 T03–T08。

## 1. 目标

让授权状态成为可刷新、可测试的真实状态；把 .limited 零照片从普通 .empty 中分离出来。T02 不做完整授权页 UI，只保证状态模型正确并能驱动根视图。

## 2. 生产改动

### 2.1 PhotoDesk/Core/Photos/PhotoLibraryService.swift

- 增加 statusProvider / requestProvider 构造注入，默认读 PHPhotoLibrary。
- 增加 @discardableResult func refreshAccess() -> LibraryAccess：
  - 调 statusProvider；
  - map；
  - 与 access 不同则更新；
  - 返回最新值。
- requestAccess() 改走 requestProvider。
- 可增加 requestAccessIfNeeded()（notDetermined 才 request，其他 refresh）。
- 保持 LibraryAccess 映射不变；不改 presentLimitedLibraryPicker。

### 2.2 PhotoDesk/Features/Library/LibraryViewModel.swift

- ViewState 增加 .limited。
- start() 先 service.refreshAccess()，再 switch；.limited 与 .authorized 都 loadIfNeeded，但 isLimitedAccess 正确设置。
- loadIfNeeded() 的 totalCount == 0 分支：viewState = isLimitedAccess ? .limited : .empty。
- 增加 refreshAccessAndReload(force: Bool = false)：
  - previous/current 比较；
  - 需要时取消 indexingTask、重置 hasLoadedOnce / isIndexComplete / 数据数组；
  - await start()。
- 增加 limitedPickerNeedsReload 标志与 requestManageLimitedPhotos() 的置位逻辑（T03 接 UI）。
- requestAccess() 后刷新并 reload；不要重复弹系统框。

### 2.3 PhotoDesk/Features/Library/LibraryContainer.swift

- 根 switch 增加 .limited 分支，先接 DSEmptyState(kind: .limited)（T03 再加按钮/ID）。
- 不要求 T02 完成 scenePhase 刷新；但如新增 case 导致编译，必须补齐。
- 不改 PermissionIntroView 的最终文案（T03）。

## 3. 测试

### 3.1 PhotoDeskTests/PhotoLibraryServiceTests.swift（新增）

- initialAccess 注入 notDetermined/denied/limited/authorized。
- statusProvider 返回 denied，再返回 authorized：refreshAccess 第一次 denied，第二次 authorized，access 发布变化。
- requestProvider 返回 limited：requestAccess 后 access == .limited。
- 非有限/未知状态映射安全（按现有 map 规则）。

### 3.2 PhotoDeskTests/LibraryViewModelAccessTests.swift（新增）

- 复用现有 MockAssetRepository / MockImagePipeline；若不足，在测试 target 补最小 fake。
- service 初始 .limited，repository 返回 0：start() 后 viewState == .limited，不是 .empty。
- service 初始 .authorized，repository 返回 0：viewState == .empty。
- service 初始 .denied，refresh 后变 .authorized：refreshAccessAndReload 后 viewState == .ready 或 .loading 结束为 .ready（按 mock 数据）。
- force reload 时 indexingTask 被取消、hasLoadedOnce 重置（用测试可观察字段或行为断言）。

### 3.3 编译测试

- LibraryContainer 六态 switch 必须穷尽；不能靠 default 吞掉 .limited。

7. 更新 progress-m20.md；commit：feat(library): 增加照片授权刷新与受限空态。

## 5. 验收

- .limited + 0 张 → .limited；.authorized + 0 张 → .empty。
- refreshAccess 能在 denied → authorized 时更新 access 并触发重载。
- requestAccess 只在 notDetermined 弹系统框；denied 调用不假装成功。
- 无新增 iOS 17 API；无 try! / 强制解包。
- 单元测试全绿；app target 编译通过。
