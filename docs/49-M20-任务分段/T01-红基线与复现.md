## 3. 测试设计

### 3.1 testLongPressAnchorSelectsExactlyOneCell

- 启动普通网格：复用 RowBandSelectUITests.launchPlainGrid 的 launchArguments：
  - -uiTestingSeedDatedPhotos
  - -uiTestingClearPosition
  - -uiTestingKeepChrome
  - -uiTestingFilterYear 0
  - -uiTestingLongPressMovement
- 等网格稳定 1.5s。
- 对 collection.cells.element(boundBy: 0) 执行 press(forDuration: 0.8)。
- 断言 Selection-Count == 1，且只该 cell 的 selected 状态为 true。
- 当前预期失败：实际会选中整行（4 张或更多）；失败信息必须打印 count 和 AX hierarchy 摘要。

### 3.2 testSelectButtonDirectHorizontalDragStartsTrail

- 启动时额外加 -uiTestingSelectMode，使「选择」按钮已进入多选；也可启动后点 Library-Select。
- 取首行前 4 个 cell 的 frame，从 cell0 中心拖到 cell3 中心（press 0.05s thenDragTo）。
- 断言 Selection-Count == 4。
- 当前预期失败：实际 count == 0；记录「触摸被消费、滚动被禁用、无 trail」的调试字段（若 DEBUG 可读）。

### 3.3 testDeniedScreenOffersSettings

- 启动参数增加 -uiTestingPermissionState denied（T03 才实现；T01 先写测试）。
- 断言存在按钮 ID Permission-Open-Settings。
- 断言不存在「重新检查授权」作为主按钮（若存在也只能是次按钮）。
- 当前预期失败：页面仍是 intro 或没有该 ID。

### 3.4 testLimitedEmptyOffersManage

- 启动参数增加 -uiTestingPermissionState limited 与 -uiTestingEmptyLibrary。
- 断言存在按钮 ID Permission-Manage-Limited。
- 断言不存在普通空态文案「去拍一张或导入几张试试」作为唯一内容。
- 当前预期失败：落到普通 .empty。

### 3.5 testAuthorizedEmptyOffersImport

- 启动参数增加 -uiTestingPermissionState authorized 与 -uiTestingEmptyLibrary。
- 断言按钮 ID Library-Import 存在。
- 当前预期失败：普通空态无按钮。

## 4. 执行步骤

1. 写测试文件，先确保编译（测试只引用现有公开 ID/launchArguments；新增参数不会编译失败）。
2. 本地运行能跑的部分：
   - powershell -ExecutionPolicy Bypass -File scripts/test-core.ps1
   - 记录 Core 基线（本卡不改 Core，应该全绿）。
3. 推送分支，触发 GitHub Actions macos-15 + Xcode 16.4 的 UI 测试 job（模拟器 runtime 以 workflow env 为准）。
4. 只运行 M20RedBaselineUITests（xcodebuild -only-testing:PhotoDeskUITests/M20RedBaselineUITests），记录 4 条失败。
5. 把命令、run id、失败摘要写入 artifacts/plan/m20-baseline.md；不要修生产代码让测试变绿。
6. commit：test(m20): 增加三条问题的红基线用例。

## 5. 验收

- 4 条测试都能编译并运行。
- 4 条都因预期根因失败，不是环境/超时/找不到网格。
- 失败输出包含 expected / actual / hierarchy 摘要。
- git diff 只含测试与基线记录。
