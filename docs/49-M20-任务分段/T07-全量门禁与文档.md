## 2. 必跑门禁

### 2.1 本地 Core

    powershell -ExecutionPolicy Bypass -File scripts/test-core.ps1

要求：PhotoDeskCore 全部测试通过，exit 0；记录测试数量与耗时。

### 2.2 GitHub Actions 全量

- 推送 T06 的 commit，触发 .github/workflows/ios.yml。
- 不使用 test_filter，跑全量（workflow 默认 skip PerformanceUITests）。
- 记录 run id、core-linux 结果、build 结果、失败附件（如有）。
- 注意 workflow 顶部 IOS_RUNTIME / MINOS_VERSION 是单一真值；当前 MINOS_VERSION = 16.0，模拟器 runtime 以 workflow env 为准。不要在代码/脚本里散落版本号。

### 2.3 静态审计

- iOS 17 API：
  - grep -R "@Observable\|ContentUnavailableView\|SwiftData\|scrollPosition\|scrollTargetBehavior" PhotoDesk PhotoDeskCore
  - 期望零命中（文档/注释除外，需人工确认）。
- 永久删除：
  - grep -R "彻底删除\|永久删除\|permanently" PhotoDesk
  - 删除路径只能 PHAssetChangeRequest.deleteAssets。
- 第三方依赖：
  - 检查 Package.swift / project.yml 无第三方 package。
- PhotoDeskCore 依赖：
  - grep -R "import UIKit\|import SwiftUI\|import Photos\|import PhotosUI\|import Vision\|import CoreImage\|import Accelerate" PhotoDeskCore
  - 期望零命中。
- 强制解包：
  - grep -R "try!\| as! " PhotoDesk PhotoDeskCore
  - 人工确认 IBOutlet 例外。
- 魔法数字：
  - 新增 1.2、60、0.8 等必须进 SlideSelectConfig / DesignSystem；grep 新文件。

### 2.4 产物结构

CI 的 Verify deployment target / Verify unsigned ipa 必须通过：

- minos = 16.0；
- MinimumOSVersion = 16.0；
- Payload/PhotoDesk.app/PhotoDesk 存在；
- codesign 不显示 Signature；
- Info.plist 权限文案齐全。

### 2.5 性能/内存

- 若 CI 有 XCTMemoryMetric / 性能结果，记录峰值；目标 < 250MB。
- 滚动 FPS 以真机为准；无设备则标 BLOCKED，不伪造 55 FPS。
