# T05 — 手势锚点与选择接线

> 依赖：T04。状态：⬜。预计：1d。
> 只读：00-索引、本卡；可读 SelectionGestureMachine.swift、LibrarySelectionController.swift、LibraryViewController.swift、SelectionGestureMachineTests.swift、RowBandSelectUITests.swift。不要读 T06–T08。

## 1. 目标

把 T04 的混合命中接到生产手势；把 beginTrail 改成带 anchor 的唯一事务入口；让「选择」按钮进入多选后直接横拖也能开始选择。

## 2. Core 改动

### 2.1 SelectionGestureMachine.swift

- SelectionGestureEffect.beginTrail 改为 beginTrail(anchorID: String)。
- handleHoldElapsed 发 .beginTrail(anchorID: anchor)。
- pressing 横向锁定：
  - if !isSelectionModeActive, let anchor = anchorID → .enterSelection(anchorID: anchor)
  - always .beginTrail(anchorID: anchorID ?? "")
- 其他 .beginTrail 调用点全部补载荷。
- 更新 Equatable 测试与所有 switch。

### 2.2 SelectionGestureMachineTests.swift

- holdElapsed：断言 [haptic?, .enterSelection(anchorID:), .beginTrail(anchorID:)]。
- 未多选 pressing 横向：断言 .enterSelection + .beginTrail(anchorID:)。
- 已多选 pressing 横向：断言只有 .beginTrail(anchorID:)，没有 .enterSelection。
- 纵向占优：仍是 .releaseScroll，不发 beginTrail。
- anchorID 为空：beginTrail(anchorID: "") 仍发出，控制器防御性忽略。

## 3. App 改动

### 3.1 LibrarySelectionController.swift

- apply(.beginTrail(let anchorID))：
  - consumedTouch = true；
  - collectionView?.isScrollEnabled = false；
  - guard !anchorID.isEmpty else { break }；
  - trailAnchorID = anchorID；
  - started = SlideSelectTrail(base: selectedIDsProvider(), anchorInitiallySelected: anchorInitiallySelected, scope: scopeProvider())；
  - delta = started.consume([anchorID])；
  - trail = started；lastTrailContentPoint = machine.pressPoint；
  - 落地 delta；onTrailActiveChanged(true)。
- 删除 beginTrail 内的 rowBandHitProvider(press,press) 分支；起手绝不整行。
- processTrail 使用 trailHitProvider 返回的 GridTrailHit：
  - .cells → consume(orderedIDs)
  - .rows 且 rewindID == nil → 首次进入行模式先 rebase（base=selectedIDsProvider、mode 保留、path 清空，consume 当前行完整 left-to-right 种子）；再 consume(orderedIDs.filter { !current.path.contains($0) })
  - .rows 且 rewindID != nil → path.contains(rewindID) ? consume([rewindID]) : consume(orderedIDs)
- 保留 apply 窗口空命中不前进；过滤后为空视为成功帧，lastTrailContentPoint 前进。
- 删除/重命名 rowBandHitProvider 引用；旧 provider 不再被生产代码调用。

### 3.2 LibraryViewController.swift

- rowBandHitProvider 改名 trailHitProvider，类型返回 GridTrailHit。
- 注入闭包：
  - 调 hitTester.trailHitTest(from:to:clipTop:)；
  - indexPaths → dataSource.itemIdentifier → ids；
  - rewindIndexPath → rewindID。
- Library-Select 仍只负责 toggleSelectionMode / enterSelectionMode。
- enterSelectionMode 同步 machine.isSelectionModeActive = true；exit 设 false。
- 不改变纵向滚动让位：pressing 纵向仍 releaseScroll。
- 不改变轻点选择、长按触觉、自动滚动、跨月 scope。
