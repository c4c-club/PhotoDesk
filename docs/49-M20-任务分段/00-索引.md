## 1. 执行铁律

1. 开始任何任务前，只读本索引和当前任务卡；不要一次性读全目录，不要读后续卡片，不要读旧 docs/42/43/44 的冲突段落。
2. 回复格式固定：先回复「已读 Txx」，再列出本任务要改的文件，然后开始执行。
3. 一次只做一个任务；完成、测试、更新进度、commit 后，才允许读下一张卡。
4. 红测试优先：T01 先把三条问题变成可复现失败；后续每个行为修复先补对应失败用例，再改实现。
5. 不修改本任务卡之外的文件，除非编译/测试必须；若必须扩展，先在进度文件记录原因。
6. 不伪造测试结果；Windows 无 Xcode 时，本地能跑的只有 Docker Core 测试，iOS 结果必须来自 GitHub Actions。
7. 任何 BLOCKED 必须写清：阻塞点、已尝试命令、缺少的环境、下一步；不得用「应该可以」替代证据。
8. 每个任务结束更新 artifacts/plan/progress-m20.md 和本索引状态；commit 格式按 AGENTS.md。
9. 完成 T08 才允许宣布 M20 完成；IPA 路径、SHA256、CI run id 必须可核验。
10. 全流程遵守 AGENTS.md：iOS 16、0 第三方依赖、PhotoDeskCore 只 import Foundation、无永久删除、无 iOS 17 API。
